## 重现

从仓库根目录运行，安装 Pillow、NumPy、Matplotlib，并使用 FFmpeg 或 imageio-ffmpeg。

```sh
skill=.agents/skills/design-cloth
PYTHONPATH="$skill/scripts" python3 -m unittest discover -s "$skill/evals" -p test_clo_motion_batch.py -v
python3 -m unittest discover -s .agents/skills/clo-fit-export/scripts -p test_fold_preview.py -v
python3 "$skill/scripts/clo-motion-batch.py" --config /path/to/config.json --out /path/to/review --jobs auto
git diff --cached --check
```

CLO Python 能力以原生 SDK 回读为准。按 `index.html` 和 `stats.csv` 分别核对画面与数值。原生录制/取证、服装统计与目视结果分别记录。
