## 检查了什么

检查器从原始文件重新解析多段线、核对语义注册和摘要，再检查实际导出GLB的源二维面域、顶点与三角面对应关系。五个面域分别是前身、后身、左右袖及折叠领条的可见外层。它检查全部裁片边界覆盖和面积，确保声明纳入外壳的面域没有用连接面遮住缝隙或丢掉局部区域。

15条缝包括左右肩、左右侧缝、左右袖底、左右袖窿的前后段、领口的四个对位段及领条短边。缝合边必须共用顶点，具有两个相应来源面的邻接；只检点距不足以通过。局部吃势区间、前后方向及领条原有后中／肩点／前中标记同时核对。

三角面穿插使用仓库 `independent_oracle_v2.py` 的严格实现，复制到服务 `verification/geometry.py` 后源摘要仍为 `685fea10301c57b733f98c8e3a1bc26b0f1ed249561a2589b9b0d18bec48d1a9`。它覆盖共面正面积重叠，也检查共享顶点或边的面；仅合法的点／边接触不计穿插。

## 原版与修正

原版肩缝相差约2.388毫米；侧缝计入前片溶6毫米、后片拔10毫米后仍差约2.509毫米；袖底差约2.488毫米。原袖山吃势约前6.044／后1.486毫米，按项目袖子规则40%／60%重新配为约前3.012／后4.518毫米，保持衣身袖窿不变。领条保留原对位分段，修正后与领圈的长度比约0.8074；面料能否承受所需拉伸未实测。

修正只写入派生缝合线：前肩及相接领口、前侧及相接衣摆、袖山、袖底及袖口。原始DXF摘要仍为 `1f82b2c4ca094983657ce49fc73cf06aec24d3329a53dcc3472dd5ca2cee87f4`。离线包包含原文件、`pattern-revision.json`、`corrected-seam-lines.svg` 与逐缝报告。它们是连接核查资料，不是已批准的含缝份生产母版。

已发布v1源码 `0f9edae` 可通过 `scripts/reproduce_dxf_v1_baseline.py` 重建原GLB，摘要 `de34bed5…`；对其实际字节独立复测为9个组件、12个边界环、340对穿插，见 `baseline-v1.json`。这与更早历史布料实验的7.6455毫米接缝间距／20处自交FAIL是两组不同证据，均未被覆盖。

## 对照与修复过程

27项测试通过，其中包含检查器的23个解析对照。故障模型覆盖错误源摘要、交换前后标签、隐藏吃势、漏缝／反向配对、重合但未焊接、3毫米开缝、删除面形成内洞、翻面、前片穿过后片、共享边共面折叠、整件内外颠倒及隐藏的GLB节点镜像。所有预期错误均被拒绝；刚体变换后的合法模型仍通过。

初次回归失败完整保留。随后修复了Qhull忽略共线边界点及缺少约束边的问题，通过对角翻转与沿真实边界点拆分面恢复边界；对规范化坐标作1纳米精度量化，消除单位换算／平移后的数值分叉。导出证书的二维面积在读取实际float32数据后用float64计算，避免大坐标下的求和误差；阈值未放宽。

方向检查还使用仅用于判别的虚拟开口封盖，检查有向体积为正；这些封盖不写入模型，也不参与开口与真实穿插计算。

旧的全模型高度断言依赖原先垂臂姿态；修正版采用A姿，改用实际袖底缝长约455.842毫米的独立约束，并保留米制范围检查。原来的整条侧边平移正例会留下两个开口端点，现在作为拒绝用例保留；合法的局部改形正例固定端点，并继续要求输出改变。原先9网格的实现断言改为一个焊接网格、五个来源面域及完整拓扑检查。

本地浏览器的16组验收通过，包括数值结果、旋转缩放、真实上传、复用、模型／原始文件／修正线／逐缝报告下载、离线打开和无WebGL回退。独立命令再次检查下载的GLB。完整原始报告和截图在 `local/`。

## 范围

此PASS批准的是修正版静态外壳的数字几何连接。领条隐藏内层、缝份叠层、物理布料仿真、人体碰撞、真实放码、制造工艺及试穿合身均不在此证书内。毫米解释、一片完整后身及A姿是显式装配假定，原后身数量2的含义仍需制版核对。不得从本次结果推断生产纸样或实物样衣已合格。
