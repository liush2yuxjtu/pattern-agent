# 后臀覆盖修复与接触反力核验

## 问题与修复

之前的默认首页显示未经重力和碰撞求解的初始衣片。独立的后臀投影检测在
153 个人体顶点中发现 52 个裸露点；加入 313 个人体面中心后，共 466 点中
150 点裸露。没有三角形相交不能替代服装覆盖检查。旧截图的 Back 名称也
不能证明实际背面：按需绘制可能保留上一帧。本次相机预设会立即绘制。

正常打开、UI Reset 和修改版型现在先执行 120 个实际 WASM 重力、人体接触
和布料自接触子步，再显示裙子。没有删除人体、裁掉臀部、缩小模型或改用
透明遮挡物。`clothLab.reset()` 保留为显式的未松弛诊断入口，必须判 FAIL。

新增 Pressure 视图保存实际人体法向位置修正的逐步累计值。自由顶点采用
F = m Δn / Δt²，p = F/A；单位 kPa，排除固定腰部支撑反力。独立 Python
审计从真实 FreeSewing UV 三角形重新计算面积和质量，不导入应用计算函数。
对删除衣片、未下垂衣片和伪造压力都保留拒绝控制。该估算依赖时间步长和
投影顺序，**没有经过面料或人体压力实测标定**，不能冒充真实舒适性评估。

## 验收边界

- 466 个后臀采样点全部遮挡；检测范围与方向写入报告，不宣称任意视角的连续覆盖证明。
- 120/240/360 步和最大风力后的 480 步：独立三角形人体相交、自相交和人体内部顶点均为 0。
- 实际 UI 修改至 650 mm、60% 圆裙、亚麻后，120 步状态通过相同独立检查。
- 4 对有方向、有对应刻口的缝线，最大间隙 0 mm；一片缝合壳和两个预期开口。
- 应力、应变、折角、曲率和压力：独立数值重算，并读回真实 WebGL 绘制颜色，每图 32,256 个分量。
- 离线单文件保存/恢复包括压力场，下一步物理坐标完全一致。
- 120 步 A/B 从同一未松弛诊断状态开始，与真实 2.0 HTML 的当前/上一帧/材料坐标逐位相同；压力观测不改动物理轨迹。

应力为未标定平面应力材料模型的第二 Piola–Kirchhoff 主拉应力；伸长率
100% 表示静长。默认 360 步峰值伸长率仍为 189.5%（88/3584 个面超过
120%），因此**真实面料合体、压力舒适性、生产工艺验收仍为 NOT_VALIDATED**。
数字几何、字段算术和显示通过，不能转换成这些物理标定声明。
