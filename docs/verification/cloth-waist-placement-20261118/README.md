## 新验收边界与反例

页面要求腰口间隙 3–10 mm、装配定位误差 ≤1 mm、实际腰口与纸样长度差 ≤1 mm。独立 `fit_oracle.wear` 不读取渲染器装配文件，从原始人体测量路径重算高腰高度，逐三角形切平面，要求一个闭合轮廓；以 float64 查询真实皮肤，另外要求最近点腰位误差 ≤2 mm。61 个保存帧均包含该检查。

真实浏览器中分别把腰口向外移动或上移 30 mm，连同固定点和历史位置一起恢复；两种状态保持接缝闭合、臀部覆盖，但 UI 与独立腰口检查都必须拒绝。[反例截图与结果](local/fit/receipt.json)保留。

另有[四项几何探针](local/waist-probes.json)：实际工程通过；离体腰口被拒绝；沿错误高度的真实皮肤重新贴合、间隙仍为 3–10 mm 的腰口，必须因腰位错约 31.8 mm 被拒绝；纸样腰口增加 20 mm 而几何不变，必须因长度不符被拒绝。

首次编写独立截面检查时，错误假定至少需要 100 条切段。实际闭合截面有 84 段。已用真实数据证明确为单个闭合轮廓，将无依据的分辨率假定改为闭合性／连通性检查；[最初失败](invalid-section-density-assumption/)与[诊断](section-test-diagnosis.json)保留。穿透、接缝、压力和腰位容差没有放宽。
