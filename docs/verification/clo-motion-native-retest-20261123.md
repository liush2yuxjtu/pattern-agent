# Boat 原生 CLO 动作录制复验

在单席授权的专用 Boat Wine worker 上用 CLO 2026.1.382 复验。S、M、L、XL 的起始工程来自同一版 FreeSewing 六片裁片和 14 个缝合组。工程和原生媒体由工作区保管。

## 批处理入口

| 验证项 | 结果 | 实际证据 |
| --- | --- | --- |
| 已保存起始工程读回 | PASS | M 码六片面积与保存后基准一致，14 个缝合组。直接 FBX 路线加载服装后为 0 个人台，导入动作后为 1 个 |
| 原生动画录制 | PASS | M 码自然站立动作完整录制 91 帧，原生工程范围 0–132，前 42 帧用于预热。五个抽查动作帧准确对应原生帧 42、64、87、109、132 |
| 文件传输和审查生成 | PASS | SSH 连接中断时经 Boat 命令通道传输并回读 SHA-256。复跑从 worker 缓存取入三份输入。批处理生成 40 行待验收表、原生录制视频和快照 |
| 自动定量取证 | BLOCKED | Python 原生缩略图在该版本可能把应力与应变保存为同图。缺少压力或读数会阻塞自动判定 |
| M 码自然站立抽查 | PASS | 复读五个原生帧的点测标签。压力最高 0.27 kPa、应力 5.41 kPa、应变增量 37.06%、各裁片最高折角 P95 为 27.41°。每帧 72 个覆盖探测点均有覆盖，布料与人台及布料自身相交均为 0 |
| S 码自然站立抽查 | PASS | 五帧完成原生点测、网格统计及目视复核。压力最高 0.20 kPa、应力 5.86 kPa、应变增量 30.31%、各裁片最高折角 P95 为 31.53° |
| M 码双臂前伸抽查 | PASS | 七帧完成原生点测、网格统计及目视复核。压力最高 0.04 kPa、应力 5.16 kPa、应变增量 39.51%、各裁片最高折角 P95 为 44.96° |

自然站立 M 码从原方案的袖口加放 18 mm。人体腋下局部形变由同尺码 V4 工程的人台表面校正。复验检查源关节轨迹、CLO 录制的身体表面和同帧服装数据。应变以 100% 为零伸长基准。原生点测的最大值覆盖报告所列样本。逐值核对原生标签可修正 OCR 对袖口边缘和小数的误读。

直线走秀已按 30 fps 录制 499 源帧。固定机位会漏拍行进中的人台。第 210 个源动作帧仍检出布料穿插。四码十动作整体验收持续复验。

```sh
skill=.agents/skills/design-cloth

```
