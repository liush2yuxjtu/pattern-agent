## 真正操作过的流程

在正常HTTPS的云端Chrome中，使用 `cua_repl` 的浏览器API与原生界面：

1. 打开案例库，看到5个真实模型；筛选可查看缝合2件、待配置3件。
2. 输入“前领深 +10U”只剩1件；组合缝合筛选得到0件，点击清除恢复5件。
3. 切换二维纸样，真实CAD轮廓取代三维画面；再切换回三维。
4. 打开袖口案例，阅读完整意图与完整中文YAML，实际下载DXF。
5. 点击原型与改版对照，原生选择框实际选中 `03_cuff_width`。
6. 实际后退回案例；切换实验说明，保留9个目录目标和源README摘要。
7. 从说明进入项目文档、缝合页，再分别点击返回入口回到案例库。

[report.json](report.json) 保存实际观察及应用日志。下载的
[cuff-output.dxf](cuff-output.dxf) 为108836字节，SHA-256
`7436ccd3bae9fe3746922db35646a0bed3ab1304e8a867fa202da2b592c62163`，
与仓库实际输出逐字节一致。线上读取的完整YAML为196859字节，摘要同源规格。

截图：[实际画廊](public-gallery.jpg)、[二维预览](public-2d.jpg)、[案例详情](public-case.jpg)。

全部18次下载、五个案例跳转、五种宽度、CPU及断网仍见本地完整验收。
