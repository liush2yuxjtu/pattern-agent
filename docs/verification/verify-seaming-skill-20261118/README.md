# 项目级接缝验证技能

新增独立的 [verify-seaming 技能](../../../.agents/skills/verify-seaming/SKILL.md)，
把原有接缝几何、交互验收、生产 Site 和 Pages 保存流程组织成可复用的项目入口。
本次只新增技能、共用路径与文档入口，不改变生成器、阈值、模型、网站或访问范围。

## 技能入口与边界

规范源为 `.agents/skills/verify-seaming/SKILL.md`，Claude 的同名技能是指向该目录的
相对符号链接。可显式请求 `$verify-seaming`。该技能依赖本仓库的检查器与样例，
属于项目级技能；没有声称复制单个文件即可在任意项目独立运行。
本轮验证文件结构及命令，不声称原生客户端自动发现、路由触发或通用纸样成功率。

按声明依次组合现有配方：

| 声明 | 必需证据 |
| --- | --- |
| 裁片正确连接 | 原 DXF、修正线、实际导出 GLB 的独立来源、走缝、UV、拓扑和穿插审计 |
| 交互视图可信 | 所有显示数组、标签与报告绑定实际模型，实际点击、触摸、保存恢复和下载 |
| 生产网站能用 | 准确源码与发布版本、授权会话、真实生产网址交互及下载重开 |
| Page 已保存 | 原生文件访问回执、大小/摘要、带块哈希的编辑、独立内容读回 |

规范阈值和执行配方继续保存在既有 `/verify` 的四个检查面中，新增技能不另建一套算法。
原 `dxf-seams` 配方和仓库 README 均已增加新入口，其他检查面和并行工作保留。
