Generate and preview 3D garment meshes from GarmentCodeData or GarmentCode sewing-pattern JSON. Use when users provide a dataset sample folder or *_specification.json and want meshing, cloth draping, OBJ/GLB export, wireframe inspection, or a rotatable 3D garment preview, including requests in Chinese such as 纸样生成网格、三维预览、布料仿真. Distinguish an initial sewn mesh, a newly simulated drape, and an existing dataset simulation.
