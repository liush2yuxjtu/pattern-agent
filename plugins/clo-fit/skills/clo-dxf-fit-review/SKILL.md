# 从纸样到多姿势试穿

交付可打开的 CLO 工程、真实模拟图、分姿势数据和可选择的下一步。跟随用户指定的尺码、姿势、面料、输出形式与语言。输入文件夹只读，另设工作目录和交付目录。保留原版，用户选择方案后才开始改版。

## 从哪里开始

- **DXF 或纸样文件夹**：读取主版和部件文件，核对比例、裁片和缝线，再建模。具体做法见 [CLO 建模与采集](references/clo-workflow.md)。
- **已有工程**：从指定的已保存模拟开始。先用 CLO MCP 的 `clo_status` 和 `scene_info` 确认桥接、当前文件、裁片、模特和缝合组。保护当前未保存的工作。能后台完成的操作留在后台。
- **已有按姿势保存的网格、图和数据**：核实来源后直接分析。缺少可用的 CLO 或相应姿势文件时，完成可验证的部分，并标明缺失的视角或模式。

- **有设计线稿、技术平面图或原始网页**：按 [线稿与成衣外观对照](references/line-art.md) 核对来源、视角与扣合状态。没有可靠线稿时，继续完成试穿并注明参考缺项。

## 试穿与验证

1. 基准工程保存后，每个姿势从同一基准重新打开。固定纸样、模特、面料与网格设置。姿势围绕问题来选，例如长袖上衣可对比自然垂臂、原始斜展、侧平举和屈肘；裤装可对比站立、坐姿、屈膝。靠实际截图确认动作。复合动作单独命名。
2. 每姿势单独保存工程、服装网格、正背面试穿和应力截图。需要时增加侧面。用本机已安装的 **clo-fit-export** 生成应变热图、四视角折角图、平面折痕图、JSON 和 CSV。按该技能验证单位、二维原始坐标、裁片名称及顺序。
3. 单独采集 CLO 原生试身压力图，核实模式、色标和画面。区分衣料受力、衣料伸长、表面折皱、衣服对人体的压力。仅从点测或导出数值报告具体 kPa，截图只作定位。
4. 同一套网格的多姿势对比可用 [批量核对与统计](references/compare.md) 和 `scripts/compare_poses.py`。逐项检查渲染图，若出现穿模、缝线扭转或着色模式错误，先纠正该姿势再作判断。
5. 有可用线稿时，从指定基准或可核实的已保存姿势取普通材质图，交付带来源、视角和状态标签的并排图及原始快照。把可见外观差异跟同版工程、缝合、量测或试穿数据核对，再提出单变量复测。
6. 按 [五部分试穿报告](references/report.md) 交付。用户要 ChatGPT Page 时使用 Pages 技能，上传真实原图，在原页或指定页写入并回读核对。只要求本地结果时交付本地报告和图。在结尾请用户选择一个方案，说明最值得先试的变量。

## 已完成的输入与输出样例

参照 [M 码 T 恤的五部分报告](assets/examples/fitted-knit-tee/report.md) 编排新的 Page。样例含[原始主 DXF](assets/examples/fitted-knit-tee/input/女紧身款T恤.dxf)、11 张试穿与热图，以及报告使用的已测数据。复用章节结构与证据排列，针对新纸样重新识别轮廓、模拟动作并计算表格中的数值。
