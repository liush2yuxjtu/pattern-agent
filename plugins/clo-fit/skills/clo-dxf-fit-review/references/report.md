# 可预览的五部分报告

用用户的语言。默认中文时，先说“手放下，袖口盖到手背”，再在图注中给出技术名。部位和结论来自当前服装。

1. **现在哪里值得改**。每处写观察、可能解释和可试的改法。写清设计分支，例如齐腕款和盖手款对袖长有不同要求。把无法从纸样判断的设计意图留给用户。
2. **整体看起来怎样**。有可靠线稿时先放线稿与普通材质外观的并排图，标注来源、工程版本、姿势、视角和已知扣合状态，并附原始快照。说明从图上可见的差异与需要工程证据确认的原因。随后并排放各姿势正背面，尽量使用同视角、同裁切尺度。局部放大或参考缺项写入图注。
3. **放大看具体问题**。先按部位提供带标签的局部图，再给应力图、应变热图、四视角折角图、试身压力图。解释每张图中哪一处支持判断。保留必要色标、单位和视角；适用时附完整图和裁片折痕图。
4. **用数字核对**。按姿势并排比较相同裁片或同一局部，写出区域如何选、分母、阈值、单位和面积权重。区分“伸长超过 10% 的布料占 48%”与“布料伸长 48%”。需要局部证据时在经验证的平面坐标上选区，用同一掩码跨姿势比较，并注明是否仅抽样。描述折角时说明网格密度；边数不能直接当成衣褶数。
5. **你想先试哪一种**。给出可执行选项和保留现版的选择；每个方案写调整位置、理由和复测动作。优先一次改一个变量。末尾直接询问用户的选择，不把建议写成已经改版。
