# CLO 批量缝合

用一份项目脚本处理一轮缝合。先读取 CLO 当前裁片、原生边索引和方向，再编译整批配对。执行后读取 JSON 回执和必要的 3D 证据，修改脚本或计划，从同一检查点再运行。

## 选择入口

- **只有 DXF、纸样或导出的边数据**：先确认各边的顺序和缝线长度。在已有 CLO 边数据时，可离线运行 `scripts/seam_batch.py --help`，再用目录、计划和回执路径做预检。
- **已打开 CLO 工程**：让 CLO MCP 的 `clo_run_python` 一次执行整份 Python 脚本或 `run_clo(...)`。同一轮能一起完成的读边、配对、计数和模拟放进这次调用。避免按 A1–A2、B1–B2 逐条发 MCP `sew` 调用。截图在原生显示完成后按需另取。
- **需要改接旧缝**：先确定能在副本上移除哪些旧缝，并准备缝合前的检查点。参考脚本用于添加计划内的组。原位替换、暗缝内线和复杂多层结构需要项目脚本明确其原生操作。

## 每轮如何验

1. **预检。** 对照原纸样及 CLO 2D，明确起终点、方向和关键对位点。每两个关键点之间单列一条配对路线。记录允许的长度差，在独立的覆盖清单里写明哪些边段必须缝到。
2. **批量运行。** 在获准修改的副本执行计划。脚本确认每次新增恰好一组，并从两片的原生缝合列表读到同一新增组。有失败或超时时先读取已保存回执和现场组数，从检查点恢复后再跑修改版。
3. **验证外观与几何。** 从 2D 缝线确认关键点和方向，在相同模特和姿势重跑后看 3D 端点、翻折、缝线扭转和穿模。若要求保留纸样，回导 DXF 核对外轮廓。若要四类试穿图，用 `clo-dxf-fit-review` 完成该部分。
4. **交付。** 留下可重跑的计划或脚本、JSON 回执、关键截图，以及通过与待查项目。原生组数和覆盖检查是两项证据，3D 模拟结果须另验。

需要运行示例、编写计划或判断回执时，读 [批处理参考](references/batch-workflow.md)。
