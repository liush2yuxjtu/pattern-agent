# 建模与采集

## DXF 到已缝合工程

- 列出尺码、主 DXF、单独部件、参考图和已有工程。主版可能已包含袖子与领子；对照形状、尺寸与数量，避免重复导入。读取普通 DXF 可使用 ezdxf；部分旧版 CAD 只输出 ENTITIES，中文文字可能使用 GBK。保留原件，必要的格式转换在工作副本中做。
- 优先用 CLO 的 DXF 导入功能，按文件实际格式选择 AAMA、ASTM 或适用导入方式。对照已知尺寸检查毫米与厘米、曲线、净缝线与含缝份的裁剪线。记下放码尺码、折线、剪口、正反面、镜像件、裁片数量和需要保留的内部线。
- 若导入后只有散线，按几何端点及标注连接同一条轮廓，绘出带编号的二维预览，与参考图核对。分清结构点和曲线采样点，核对闭合与转向；展开对折裁片时检查尺寸。绕边一圈建立“边号 → 肩、袖窿、侧缝等”的表。禁止沿用另一份 DXF 的实体下标、默认袖长或推测的放缩倍数。
- 用运行时可用的导入工具，或在 CLO 内通过 pattern_api.CreatePatternWithPoints、SetPatternPieceName 建片；按当前模特的 GetArrangementList 选择摆放点。按已核实的裁片边号与方向缝合，检查袖山和领口的对应关系，区分设计吃势与错误长度。使用来源指定的面料；无实布参数时记录所用 CLO 预设。任何简化（例如把对折领条显示为半宽）列入交付。
- 模拟后查看正背面及关键侧面，核对袖子左右、接缝、衣摆和穿模。检查裁片面积、边长或包围尺寸及缝合数量，最后保存基准 ZPRJ。仅有概念效果图不能证明工程已缝合。

## 姿势与图像

每个姿势从基准 ZPRJ 开始：scene_open → 导入兼容的 .pos（可用 import_api.ImportPose）→ simulate → 检查姿势和衣片是否稳定 → scene_save → scene_export（GLB，include_avatar=false）。菜单和 Python 签名随 CLO 版本变化，可用 clo_api_doc 查看本机签名。保存同一状态的正背面快照，用需要显示的镜头结束。记录工程、模特、面料、姿势文件、步数和网格精度。加载姿势名称成功后仍须查看模特手臂、手肘或膝盖的实际位置。

- **应力图**：可用 utility_api.SetStressMapStatus(True)，用 snapshot 拍摄各视角，再恢复显示。保存对应工程的色标。
- **应变与折角**：用 clo-fit-export 的 export_fit.py 处理每个姿势的服装 GLB。输入带已核实顺序的裁片名、工程及同姿势的应力截图。输出的应变为基于网格的工程应变；与原生 CLO 以 100% 为零伸长的色标区分。折角图的亮线可能对应衣褶或局部网格弯折。
- **试身压力图**：CLO 中文界面的常见入口为「设置 → 显示 → 试身图 → 试身压力图」，也可在 3D 视窗的试身图工具条选择 Pressure Map。界面因版本而异。确认显示的是衣服对模特的压力，核对图例和单位。若新打开工程尚无接触结果，在工作场景内用一致的短模拟刷新并记录步数。每次切换工程重新核对模式，避免将普通材质图误收为压力图。原生桥接阻塞菜单时，可暂停桥接、切换模式、恢复桥接再拍摄。无需改写 ZPRJ 内部结构。[CLO 试身图说明](https://support.clo3d.com/hc/en-us/articles/360000436368-Garment-Fit-Maps)
- **状态与缺项**：采集后恢复展示视图。超时先查 CLO 状态，核对当前工程、裁片和预期截图后再决定是否重试。若压力模式始终不可用，只标记压力证据缺失；应力、应变或着色强弱不能替代接触压力测量。
