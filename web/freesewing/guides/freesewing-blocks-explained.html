Coding Agent · 输入与实现

measurements 提供人体数据；options 提供已实现的设计选项；sa 另行控制缝份。长度用 mm，角度用度，百分比选项通常以小数传入，如 10% → 0.10。

每个 Part 的 draft() 计算 Point 和 Path；Part 依赖顺序与 Store 传递袖窿长度等中间结果。共用几何工具不表示所有原型采用相同制版公式。

谁复用了谁？

箭头表示制版代码复用。Bent 使用 Brian 身片与 Library 两片袖；Bibi 复用 Brian 的部分构造并加入自己的塑形；Noble 基于 Bella。Breanna、Sarah、Titan 不是“把 Brian 改一个参数”。

成衣款式还要增加具体结构。比如 Brian 没有完整衬衫领与门襟，Bent 没有完整大衣驳头，Titan 没有完整裤装口袋。

袖窿与袖山为何要一起重算？

先得到身片的前、后袖窿长度，再给袖片一个目标：袖山长度约为前后袖窿长度之和乘以 (1 + sleevecapEase)。Library 一片袖会迭代改变宽度与袖山高度，让曲线长度接近目标。这个吃势目标与胸围松量是两个不同参数。

4.10.2 的一片袖循环有最多 50 次、差值 2 mm 的停止条件。这是算法停止条件，不是工厂验收标准，也不是所有原型都采用的容差。Bent 的两片袖有自己的构造。

匹配缝长只能证明部分二维关系。袖子活动量、面料伸长与胸部贴合仍须另测。

工厂母版怎样接入？

可建立自己的 Design 和 Parts，保留工厂已验证的原型规则。先还原基码净缝线、丝缕、对位点与裁剪信息；再把尺寸变化、松量、省道与放码规则写成可执行代码。

导入一张 SVG / DXF 轮廓，只得到几何；它不会自动恢复母版背后的参数关系。基码重合、跨尺码对照、缝长检查与坯样确认应分别记录。
