制版师 · 原型的适用范围

Brian 是 FreeSewing 的男装衣身基础原型，由 Joost De Cock 设计并编程，参考 Gareth Kershaw 的制版方法。它处理肩斜、肩缝位置、袖窿与袖山。从胸部向下直落，不自动收腰。选择原型仍须符合目标体型与款式。

Block 是发展款式的起点。通常不会把它直接当作完成的服装设计。

制版师 · 两种余量不能混用

本例 10% 胸围松量增加 100 mm 成衣胸围。10 mm 缝份加在缝线外，不增加这 100 mm。活动量、造型量、面料弹性与工艺余量仍需专业判断。四分之一公式只说明本例的 Brian 规则。

0% 只是公式演示，不是任何面料和体型的推荐松量。Brian 源码默认胸围松量是 15%；本页选择 10% 便于计算。
Coding Agent · 规则的原始代码
points.armhole = new Point(
  (measurements.chest * (1 + options.chestEase)) / 4,
  points.cbArmhole.y
)

chestEase: 0.10 是 10%；sa: 10 是 10 mm。缝份的具体形状由裁片代码决定，对折边通常不加缝份。

制版师 · 配袖不等于已经合身

目标袖山长 = 前后袖窿总长 ×（1 + 指定袖山吃势）。正吃势时，袖山可以比袖窿长。还要检查前后袖方向、剪口、袖山形状和活动范围。上面的示意图解释关系，数字来自真实生成结果。

样衣用于核对肩线、袖窿位置、抬臂和扭转。缝长通过不能代替布料仿真或真人试穿。

制版师 · 下一步实际做什么

先核对体型与原型。再按目标衣服改领口、长度、收腰和袖型；需要时增加领、门襟、口袋与工艺余量。用接近目标面料垂感与弹性的便宜布缝试样，再调整。

基础原型和完成款式各有用途。Brian 也不会从服装照片自动推断上述设计决定。
