量体 ≠ 成衣尺寸

胸围是人体净围。平铺宽、含松量的成衣围度不可直接代入。HPS 是肩颈最高点。各尺寸的量法必须与字段定义一致。本页修改胸围时，其余 10 项保持官方示例值，不代表新的完整体型。

Brian 需要 11 项量体；可选 highBust。本例采用 @freesewing/models 的 cisMaleAdult38。它是量体数据，不是 3D 人体。Brian 量体要求 ↗

松量 ≠ 缝份
本例 10% 松量增加 100 mm 成衣胸围。缝份加在缝线外，缝合后不会增加这 100 mm。活动量、造型量与面料弹性由制版师判断；FreeSewing 执行写好的规则。不同款式的选项不同。
四分之一公式是 Brian 的具体规则。Brian 从胸部向下直落，不收腰；此公式不能直接套用到所有省道和不对称款。原型设计边界 ↗

 
规则就是可检查的函数
options.chestEase = 0.10 表示 10%。sa = 10 表示 10 mm。以下为固定版本原始源码。本页宽度断言直接对照此公式。
points.armhole = new Point(
  (measurements.chest * (1 + options.chestEase)) / 4,
  points.cbArmhole.y
)

核对缝线，不量裁剪线
袖山目标 = 前后袖窿总弧长 ×（1 + 指定吃势）。不能一律要求两段等长。这里 2 mm 是代码迭代停止条件，不是行业通用公差。缝长相合仍不能证明袖子朝向、布纹、活动量或穿着合身。

打印比例要在纸上验
SVG 带 mm 尺寸。校准页只是 100 × 100 mm 方框，不是完整纸样。打印选 100% / Actual size，关闭适应页面，实际量纸上的方框。大幅 SVG 转 PDF、A4 拼页和排料另配导出工具；浏览器页面缩放不等于纸样比例。
下载的 Brian 是基础原型。它不自动提供新款式所需的门襟、口袋、面辅料和工艺说明。

 
给 Pattern Agent 的接口
输入执行交付与验收
量体 + 设计版本 + 选项校验 → draft → renderSVG + 参数 + 验证记录
新款式说明编写 / 扩展 Design边界参数 + 专家审核
布料与人体另接仿真器碰撞、受力、动态与试穿
Agent 负责整理输入、调用规则和检查输出。制版师负责款式意图、松量与工艺判断。源码可运行，只证明这一步能复现，不能替代成衣验收。
SVG 还不是可直接仿真的服装包。需另补缝合映射、三角网格、面料参数与人体坐标。
