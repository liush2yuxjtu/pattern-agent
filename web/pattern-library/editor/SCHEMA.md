# 二维纸样重建与设计意图数据结构

把原始 CAD、可编辑的二维矢量、一维规格和设计请求保存为互相引用的版本文档。二维数据包含足以重建纸样的几何，一维规格说明量什么、怎么量、要达到什么目标。补丁把前两份数据与原始 CAD 绑定到同一版。团队可用 SVG 查看二维结果。

## 当前可执行结构

`schemas/` 中的 JSON Schema 用于校验解析后的 YAML。贴身 T 恤适配器可重建项目原始的中文 1.1 版规格，并核对矢量与 DXF。

| 文档 | 核心字段 |
| --- | --- |
| `pattern-2d/v1` | 款式、尺码、DXF 哈希、坐标轴、比例状态、裁片 ID、绘图安放点。每件裁片保存稳定的边 ID、直线和折线坐标、带方向的轮廓链、定位点和标记。来源未确认的内外轮廓用途记为待确认。 |
| `pattern-spec/v1` | 款式、尺码、量测名称、量法和实测值、缝合接口、缝段组合、裁剪要求、面料、工艺及来源规格。保留旧规格中的量测和缝合名词。 |
| `design-intent/v1` | 请求 ID、款式、尺码、原始请求文本、可选结构化操作、带正负号的改动量、单位、受保护裁片和证据引用。量法和目标足够明确时可进入编译。 |
| `pattern-edit-patch/v1` | 结构版本、适用纸样、原始意图、规范化操作、三个输入的基线和目标 SHA-256、带修改前值的二维与一维变更、DXF 组码变更。重放前检查输入原始字节。 |

重放仍读取原版 DXF，以保留未修改的原生标签。二维 YAML 可以独立绘制 SVG。导出后重新读入 CAD，量测目标尺寸和缝合接口，并保留原规格中的待批准条件。

## 扩展到不同服装时要记录的内容

| 领域 | 所需字段 |
| --- | --- |
| 来源与归一化 | 原始文件 SHA-256、压缩包和成员路径、提供方、使用条件、CAD 变种及版本、导出设置和原始单位。区分裁片局部坐标系和布局位置。记录轴向、实物比例校准来源、精度及曲线近似误差。 |
| 裁片与几何 | 按款式、基础版和放码谱系分配长期裁片 ID。保存有序的外轮廓和孔，以及直线、圆弧、贝塞尔和样条控制点。记录连接容差、原生实体句柄及分段映射。 |
| 工艺语义 | 区分缝线、裁剪线、折线、内线、省道、褶裥、丝缕、镜像、对折裁剪和材料层。给剪口和钻孔稳定 ID，并保存其所属边、方向和沿缝线距离。来源只提供形状时，标出待确认的线型用途。 |
| 一维量测 | 标明人体、成衣、纸样净线或裁剪线的测量范围。保存端点或路径、平量或周长、测量方向、尺码、单位和容差。分别记录目标、实测值、数据版本和证据。 |
| 缝合关系 | 保存两侧有序边区间、方向和对应剪口。记录松量或拉伸量以及分布区间，区分候选与批准的工艺参数。主缝线改变后重算领口贴边、门襟贴边或里布等依赖。 |
| 放码与变体 | 稳定的尺码和变体 ID、基准码到各码的对应关系、放码向量或构造规则、折线位置、左右件、裁数和面里料分配。裁数和印制编号分别记录。 |
| 设计意图录入 | 用户原话或观察和出处，改动动作、量测名、目标值与单位、影响区域、显式保留项和验收项。每次绑定一个基线版本，记录冲突和未确认字段。 |
| 放行 | 保留补丁预期量测、拓扑/缝合检查、审核人及其证据。分别记录几何交换、服装语义、原生重开和实物试穿结果。 |

## 从公开反馈写出可执行请求

一位用户反馈可复穿派克服的袖子偏短，支持“加长袖子”这个方向。出补丁前仍需选尺码、确认肩点到袖口或腋下到袖口的量法、确定改动量，并检查袖山和衣身保持原样。图册里的 23 U 来自 T 恤验收用例。 [优衣库派克服评论](https://www.uniqlo.com/us/en/products/E457373-000/00/reviews)

- 贴身 T 恤提供原生组码、候选内外轮廓、23 个量测定义和缺失实物比例的校验例子。[贴身 T 恤一维与二维原型](https://liush2yuxjtu.github.io/pattern-agent/prototype-package/)
- 直身裙和无袖衣身 DXF 涵盖毫米纸样、排版和原生样条，适配器需保留解析几何。[直身裙纸样](https://liush2yuxjtu.github.io/pattern-agent/patterns/straight-skirt-eu40.zip) · [无袖衣身](https://liush2yuxjtu.github.io/pattern-agent/pattern-library/downloads/bodice-v001.dxf)
- ET 教学工程可用于原生重开和检验导出 DXF-AAMA/ASTM。CLO 样本涵盖羽绒服、卫衣和打底裤。原生文件与导出的二维数据应成对登记，再核对定位点、曲长、安放点、放码和缝合标记。[ET 官方学习资料](https://www.etsystem.cn/News/detail.html?id=1039) · [CLO 二维 DXF 交换](https://support.clo3d.com/hc/en-us/articles/115000493067-2D-Pattern-DXF-Import-Export) · [CLO 文件格式](https://support.clo3d.com/hc/en-us/articles/115000470688-CLO-File-Formats)
- 当前研发流程分别保存意图识别、尺寸推导、改版计划、几何执行和独立验证。操作库及尺寸表进入生产前仍需校准和审核。[Pattern Agent 规则与改版对比](https://liush2yuxjtu.github.io/pattern-agent/intent-edit-review/docs/)
