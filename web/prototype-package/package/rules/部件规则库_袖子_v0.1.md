# 部件规则库 · 袖子 v0.1

> 结构：**四件套**——类型决策树（判定袖型归属）、参数表（结构参数的取值依据）、生成与工艺规则（裁片生成与工艺处理的执行规则）、校验断言（生成结果的合格判定），外加标定回写机制。
> 铁律：**袖窿来自衣身原型，袖山适配袖窿——永远不先生成袖子再反配袖窿。**

---

## ① 类型决策树

用途：根据款式信息判定袖型归属，输出袖型枚举与置信度。

```javascript
袖型识别
├─ 袖片与衣身是否分裁？
│  ├─ 分裁 → 是否越过肩点？
│  │  ├─ 不过肩点 → 装袖
│  │  │  ├─ 一片袖：衬衫、连衣裙、针织上装、夹克（多数）
│  │  │  └─ 两片袖：西装、合体大衣（袖肘收省/分割，贴体度高）
│  │  └─ 越过肩点 → 落肩袖（袖山低、袖肥大、吃势取低位）
│  └─ 不分裁或肩线重构
│     ├─ 插肩袖：袖片延伸至领窝/肩线，运动量大
│     └─ 连身袖（和服袖）：袖与衣身一体，归衣身结构问题处理
```

- 装袖之外的袖型**不另立基型**，作为基型上的结构修改序列处理
- 造型变体（泡泡袖、喇叭袖、羊腿袖等）= 装袖基型 + 展开/收褶修改操作；先判定母体袖型，再叠加变体
- 非常规袖型需人工确认

## ② 参数表

用途：为袖子结构参数提供取值依据。所有参数按四层结构组织——硬边界（越界即物理不可行，拦截）、软边界（经验合理区间，越界告警）、建议值（生成初值）、来源（门派出处，取值分歧时据此仲裁）。

### 2.1 袖山吃势（cm，按类目）

| 类目 | 硬边界 | 软边界 | 建议值 | 备注 |
| --- | --- | --- | --- | --- |
| 针织上装（T恤/卫衣/打底） | 0 – 1.5 | 0 – 1.0 | 0.5 | 弹性替代塑形 |
| 针织裙/针织连身类 | 0 – 1.5 | 0 – 1.0 | 0.5 | 同上 |
| 女式衬衫 | 0 – 3.0 | 1.0 – 2.0 | 1.5 | 薄料取下限，棉府绸取中上 |
| 梭织连衣裙/衬衫裙 | 0 – 3.0 | 1.0 – 2.0 | 1.5 | 同衬衫逻辑 |
| 女时装上衣/短外套 | 0.5 – 3.5 | 1.5 – 2.5 | 2.0 | 分割结构要求袖山服帖 |
| 夹克/牛仔外套 | 0.5 – 3.5 | 1.0 – 2.5 | 1.5（落肩）/ 2.0（正肩） | 按廓形变体拆分 |
| 大衣/风衣 | 1.0 – 4.0 | 2.0 – 3.0 | 2.5 | 配合垫肩与叠穿松量 |
| 女式西装（两片袖） | 1.5 – 4.5 | 2.5 – 4.0 | 3.0 | 上限取决于面料可归拢性 |
| 羽绒服/棉服 | 1.0 – 3.5 | 1.5 – 2.5 | 2.0 | 按面布计，充绒厚度补偿另算 |

跨类目统一约束：吃势 < 0 一律拦截；> 4.5 超出常规面料可归拢极限，仅特殊工艺可豁免，需人工确认。

### 2.2 袖山高与袖肥（互锁参数，只独立取一）

| 袖山高档位 | 典型类目 | 合体度 | 活动量 | 配合袖窿 |
| --- | --- | --- | --- | --- |
| 低袖山（含无袖山） | 针织上装、落肩夹克 | 宽松 | 大 | 深袖窿、袖窿弧线浅 |
| 中袖山 | 衬衫、连衣裙 | 合体 | 中 | 标准袖窿 |
| 高袖山 | 西装、合体大衣 | 贴体 | 小 | 浅袖窿、袖窿弧线深 |

- 互锁规则：袖窿（AH）固定时，袖山高 ↑ ⇒ 袖肥 ↓ ⇒ 贴体度 ↑、活动量 ↓。指定其一，另一个由几何关系推出，禁止单参数独立变更
- 匹配规则：**低袖山配深袖窿、高袖山配浅袖窿**（校验断言的几何依据）

### 2.3 吃势分配

| 部位 | 比例 | 依据 |
| --- | --- | --- |
| 前袖山 | ≈0.4 | 前胸侧较平 |
| 后袖山 | ≈0.6 | 肩胛骨隆起，归拢需求大 |

- 一片袖品类可用 front/back 两值近似；两片袖品类需指定吃势区段锚点（相对袖窿前后对位剪口），写入 notch_map

### 2.4 取值修正因子（在类目建议值基础上微调，调整后不得越软边界）

- **面料可归拢性**：毛呢、精纺羊毛向区间上部取；棉布、涤纶向中部取；针织不修正（固定低位）
- **廓形变体**：oversize、落肩向下修 0.5–1.0；合体、修身向上修 0–0.5
- **门派差异**：文化式、登丽美、企业私有基型同类目可差 0.5–1.0。来源字段必填；冲突时以入库原型（签核生产版）实测值仲裁；无标定数据时按指定门派取值，**不混合取平均**

## ③ 生成与工艺规则

用途：袖片裁片生成与工艺处理的执行规则。

1. **吃势恒等式**：袖山弧长 = 袖窿弧长 + 吃势。**前后分开计算、分开校验**——用总弧长合并校验会掩盖前后分配错误
2. **继承与适配**：袖窿弧线、袖窿深、前后袖窿比例从衣身原型继承，袖侧只做适配；不得为迁就袖子修改衣身袖窿——袖窿修改是衣身侧决策，回衣身阶段处理
3. **叠穿类目**：大衣、风衣的袖窿已含叠穿松量叠加，袖山适配用**叠加后的袖窿弧长**，不用净体袖窿
4. **对位剪口**：吃势必须落在对位剪口划定的区段内，按分配比例布置；均匀铺满全弧是拦截级错误
5. **袖子前倾**：人体手臂自然前倾，袖中线有前倾角——两片袖通过大小袖片分割实现，一片袖通过袖肘省或袖中线偏斜处理；合体度越高越不可省略
6. **输出形态**：输出修改操作序列，不输出裸坐标
7. **放码场景**：吃势不随号型等比缩放；号型间吃势变化 ≤ 0.2cm，防止放码后吃势漂移越界

## ④ 校验断言

用途：判定袖片生成结果是否合格。拦截级违反即生成失败；告警级需人工确认或记录理由后放行。

**拦截级**

- 袖山弧长 − 对应袖窿弧长 ∉ [硬边界]（前后分开校验）
- 前袖山吃势与后袖山吃势分配颠倒（后 < 前）
- 袖山高与袖肥组合违反互锁关系（改其一未联动另一）
- 吃势未按对位剪口区段布置，均匀铺满全弧
- 针织类目吃势 > 1.5cm（面料不归拢，必起皱）
- 吃势 < 0（负吃势）

**告警级**

- 吃势越出软边界但在硬边界内
- 袖山高取值越出该类目经验区间
- 袖山高-袖窿深匹配关系违反（低袖山配浅袖窿或反之）
- 使用未经样衣标定的先验值且为首版样衣

## ⑤ 标定回写

- 首版样衣是标定实验而非成品验证。版师调版确认后，将实测最优吃势/袖山高回写为对应"类目 × 物料档案"下的建议值，并标记为已标定
- 保留"先验值 → 标定值"的变更记录；积累多款后收敛软边界；硬边界仅随物料体系变更调整
- 先验表值与团队手感的差异 = 第一批企业私有数据
