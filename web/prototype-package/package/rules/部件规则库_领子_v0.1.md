# 部件规则库 · 领子 v0.1

> 结构：**四件套**——类型决策树（判定领型归属）、参数表（结构参数的取值依据）、生成与工艺规则（裁片生成与工艺处理的执行规则）、校验断言（生成结果的合格判定），外加标定回写机制。
> 铁律：**领片适配领圈——先定衣身领口（开深/开宽），后做领；领下口永远以最终领圈弧长为基准。**

---

## ① 类型决策树

用途：根据款式信息判定领型归属，输出领型枚举、领口线形态（无领时）与置信度；同时记录图上可见的工艺线索（滚边、包条、罗纹肌理）。

```javascript
领型识别
├─ 有无领片？
│  ├─ 无领（只有领口线）→ 记录领口线形态：圆领/V领/方领/一字领/U领
│  │     └─ 处理方式由工艺决定：滚边 / 包条 / 贴边 / 罗纹（见③）
│  └─ 有领片
│     ├─ 罗纹领：针织领条，无领面领底之分（T恤、卫衣）
│     ├─ 立领：领片竖立、不翻折（中山领、旗袍领、立领衬衫）
│     ├─ 翻领：领片翻折
│     │  ├─ 平翻领（坦领）：领座极低或无领座，领片摊在肩背（娃娃领、海军领）
│     │  ├─ 企领（衬衫领）：有明显领座 + 翻领两段结构
│     │  └─ 驳领（西装领）：领片与挂面连裁翻折，有串口与驳头（西装、大衣）
│     └─ 特殊类：连帽 / 飘带（系结）/ 荷叶边领 —— 按"领型 + 造型变体"记录
```

## ② 参数表

用途：为领子结构参数提供取值依据。参数按四层结构组织——硬边界（越界即物理不可行，拦截）、软边界（经验合理区间，越界告警）、建议值（生成初值）、来源（门派出处，取值分歧时据此仲裁）。

### 2.1 无领/罗纹领：罗纹参数（两个参数必须独立）

| 参数 | 硬边界 | 软边界 | 建议值 | 说明 |
| --- | --- | --- | --- | --- |
| 罗纹宽度（cm） | 1.0 – 4.0 | 1.5 – 2.5 | 2.0 | 款式决定，独立参数 |
| 配比系数（领口） | 0.70 – 0.95 | 0.78 – 0.88 | 0.82 | 领条长 = 领圈弧长 × 配比，独立参数 |

- **配比体系按部位分立**：领口、袖口、下摆的配比系数各自独立给值，不共用（罗纹宽度亦然）
- **配比修正因子**：罗纹弹性回复率好 → 配比可向上（接近 0.88）；回复率差/久穿易泄 → 向下收（接近 0.78）。修正后不得越软边界
- 领圈弧度越大（深 V、大方领）配比越向下修——弧长变化率大，直罗纹条贴合差

### 2.2 立领（cm）

| 参数 | 硬边界 | 软边界 | 建议值 | 说明 |
| --- | --- | --- | --- | --- |
| 领座高 | 1.5 – 6.0 | 2.5 – 4.0 | 3.0 | 旗袍领偏高，衬衫立领偏低 |
| 上口相对下口缩量 | 0 – 3.0 | 0.5 – 2.0 | 1.0 | 上口贴颈必须内收 |
| 前领起翘 | 0 – 2.0 | 0.5 – 1.5 | 1.0 | 不抵下颌 |

### 2.3 企领（衬衫领，cm）

| 参数 | 硬边界 | 软边界 | 建议值 | 说明 |
| --- | --- | --- | --- | --- |
| 领座高 | 1.5 – 4.5 | 2.5 – 3.5 | 3.0 | — |
| 翻领宽（后中处） | 5.0 – 10.0 | 6.5 – 8.0 | 7.0 | 款式决定，宽度大需同步加大外口松量 |
| 领尖长 | 5.0 – 10.0 | 6.0 – 8.5 | 7.5 | 与翻领宽协调（告警级交叉检查） |
| 翻折线松量系数 | 见 2.4 | — | — | 领座+翻领两段结构的翻身量 |

### 2.4 翻领外口松量（企领/驳领的核心结构量）

- 机理：翻领翻折后，外口走的是以颈侧为轴的更大半径弧线，**外口弧长必须大于领下口**，差值不足则领子翻不下来、卡脖子
- 先验公式：外口松量 ≈ k ×（领座高 + 翻领宽），k 软边界 0.4 – 0.6，建议值 0.5（门派差异大：文化式与登丽美算法不同，来源字段必填）
- 该参数为**拦截级校验对象**（见④），建议优先标定

### 2.5 驳领（西装领，cm）——关键参数（最小集）

| 参数 | 软边界 | 说明 |
| --- | --- | --- |
| 驳口深度（第一扣位） | 款式定 | 决定翻折起点 |
| 串口斜度 | 15° – 45° | 领与驳头的分界角度 |
| 驳头宽 | 6.0 – 10.0 | 与翻领宽、串口协调 |
| 翻领宽 | 3.5 – 5.5 | 驳领翻领段 |

> 驳领是领类中最复杂的结构，本表为最小集；挂面连裁、领底呢工艺、归拔配合随西装品类跑通后补全。

## ③ 生成与工艺规则

用途：领片裁片生成与领口工艺处理的执行规则。

### 3.1 通用规则

1. **接口先行**：领下口 = 最终领圈弧长（含缝份状态）。衣身领口开深/开宽有任何调整，领片必须重适配——领子永远是后手
2. **对称性**：领片默认左右对称生成；款式声明不对称（斜领、单飘带）时按声明执行并标注
3. **纱向**：领面默认斜纱或直纱按领型规则（立领直纱、滚条必斜纱 45°）；对条格/倒顺毛面料的领面纱向为强制声明项
4. **领面/领底差**：翻领类领面要比领底大出外口松量 + 厚度翻折量（领面翻过领底所需的容量），厚料按厚度工艺补偿追加

### 3.2 领口工艺 → 领圈缝份处理与裁片形状对照表

**工艺不是补充说明，是结构参数——不同工艺对应不同的领圈缝份处理和裁片形状，须在确定结构方案时一并定案：**

| 领口工艺 | 领圈缝份处理 | 裁片形状变化 |
| --- | --- | --- |
| 滚边（细滚） | 领圈缝份收窄至 0.7–0.8 | 滚条 45° 斜纱另裁：宽 = 4×成品滚边宽 + 2×缝份，长 = 领圈弧长 × 1.0（直领圈可减 3–5%） |
| 包条（内包） | 缝份 1.0，包条包住毛边 | 包条斜纱另裁，宽 = 2×成品宽 + 2×缝份 |
| 贴边（领贴） | 缝份 1.0 | 贴边按领圈形状复制生成（另裁或连裁），宽 2.5–4.0；贴边外口加厚度翻折补偿 |
| 罗纹领 | 缝份 1.0 | 领条另裁：长 = 领圈 × 配比系数，宽 = 2×罗纹宽度 + 2×缝份；罗纹条为直条，靠配比收缩贴合 |
| 企领/立领上领 | 领圈缝份 1.0 | 领座下口 = 领圈弧长（±缩量），领座、翻领分别成裁 |

### 3.3 各领型构造要点

- **无领**：只做领口线 + 工艺处理，无领片裁片；注意领口贴边的纱向与厚度补偿
- **罗纹领**：领条接缝位置（后中/肩缝）与衣身对位登记缝合关系；领条与领圈缝合时按比例分段对位（罗纹均匀分配，不打剪口硬对）
- **立领**：上口内收（缩量）、前中起翘；下口与领圈等长 ±0.2
- **企领**：两段结构——领座下口配领圈，翻领下口配领座上口；外口松量按 2.4 施加在翻领外缘
- **驳领**：串口线定位 → 翻领与挂面连裁翻折 → 领底裁片单独处理；归拔配合（毛料品类）登记工艺档案

## ④ 校验断言

用途：判定领片生成结果是否合格。拦截级违反即生成失败；告警级需人工确认或记录理由后放行。

**拦截级**

- 罗纹配比系数 ∉ [0.70, 0.95]
- 领下口弧长与领圈弧长差 ∉ [−0.3, +0.3]（声明缩/吃量除外，须登记）
- 翻领外口松量 < 翻折所需最小值（翻不下来，物理不可行）
- 立领上口围 < 穿着者颈围（穿不进）
- 左右领片应对称而不对称（无款式声明情况下）

**告警级**

- 罗纹配比越软边界但在硬边界内
- 深 V/大方领使用直罗纹条且配比未向下修正
- 领尖长与翻领宽比例越出协调区间
- 对条格/倒顺毛面料未声明领面纱向
- 使用未经样衣标定的先验值且为首版样衣

## ⑤ 标定回写

- **优先标定对象**：罗纹配比系数（按"罗纹物料档案 × 部位"回写）、翻领外口松量系数 k——这两个参数先验分歧最大、对成衣影响最直接
- 回写单位："类目 × 物料档案"下的建议值，标记为已标定，保留变更记录
- 罗纹弹性回复率实测值进入物料档案，作为配比修正因子的标定依据
