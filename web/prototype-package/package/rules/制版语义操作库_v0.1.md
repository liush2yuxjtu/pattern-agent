# 制版语义操作库 v0.1

> 本库是"原型优先"制版体系中 LLM 唯一允许调用的修改手法全集。封闭枚举：LLM 只选操作、填参数，不发明操作、不输出坐标。
> 每个操作按四要素定义：**参数 / 前置条件 / 操作步骤 / 校验规则**
> 操作步骤（expansion）用几何内核积木写成，不含具体数值——坐标由求解器在执行时从原型几何 + 规格表现算。

## 通用约定

1. **尺寸引用规则**：凡涉及尺寸数值的参数，一律引用规格表（如 `规格表.胸围`），禁止写死数字——换参数重编译即放码。
2. **省 ID 规则**：`所属片.部位省#序号`（如 `前片.腰省#1`），序号从中间向两侧编。
3. **省量记账规则**：省量一律按**省尖角 θ** 记账，不按省口宽度（省口宽 = 2×省尖到省口距离×sin(θ/2)，同一 θ 在不同位置开口宽度不同）。
4. **弧线处理规则**：受影响的弧线按 H2 规则联动（调整控制参数，不重新拟合整条弧）。
5. **seam graph 登记义务**：任何改变缝合边长度/对位关系的操作，必须在步骤末将变化量登记到 seam graph。
6. **复合操作**：标注【复合】的操作是多个原子操作的固定编排，入库仅为 LLM 调用方便，执行时自动展开。

| 类别 | 操作 |

## 一、尺寸适配类

> 本类操作把原型的"型"缩放到本款的尺寸目标。执行顺序上必须先于省、分割、部件类操作——后续操作的参数都在正确尺寸的基础上计算。

### 1. ADJUST_LENGTH 长度调整

调整长度方向部位（衣长、袖长、裙长等）至规格表目标值。

- **参数**
  - `部位`：枚举（衣长/袖长/裙长/裤长/背长），必填
  - `目标`：尺寸引用（如 `规格表.衣长`），必填
- **前置条件**
  - 该部位在原型中有对应的长度基准线
  - 目标值 − 当前值的差在该品类允许改动量范围内（超出 → 提示换原型）
- **操作步骤**
  1. 沿长度方向基准线，将下摆/袖口相关点集平移至目标位置
  2. 联动更新与该点集相交的所有线段与弧线的端点（侧缝、前中线、分割线）
  3. 受影响弧线按 H2 规则联动调整
  4. 长度差登记到 seam graph 对应缝合边
- **校验规则**
  - 调整后该部位实测长度 = 目标值（容差 ±0.1cm）
  - 宽度方向尺寸全程未变
  - 平移点集与未动部分的连接处曲线连续（无折角）

### 2. ADJUST_GIRTH 围度调整

调整围度部位（胸围、腰围、臀围、领围）至规格表目标值，含松量在裁片间的分配。

- **参数**
  - `部位`：枚举（胸围/腰围/臀围/领围），必填
  - `目标`：尺寸引用，必填
  - `分配`：各裁片/各缝的调整比例（默认按原型 H1 结构平衡体系的比例分配）
- **前置条件**
  - 目标值对应松量 = 目标 − 净体，落在"品类 × 合体度档位"软区间内（越硬区间拒绝）
  - 若该部位有纵向省穿过，省位记录完整（调整后要还原省位）
- **操作步骤**
  1. 计算调整总量 = 目标 − 当前
  2. 按分配比例将调整量分摊到各围度构成缝（侧缝、前中、后中）
  3. 各缝沿垂直于围度方向平移对应量
  4. 联动更新与该围度线相交的省位、分割点、袖窿底点
  5. 受影响弧线按 H2 规则联动；缝合边长度变化登记 seam graph
- **校验规则**
  - 调整后该部位周长 = 目标值（容差 ±0.1cm）
  - 各缝分配量之和 = 调整总量（无丢量）
  - 前中/后中的结构对称性未被破坏（除非款式单声明不对称）
  - 省尖位置未发生位移（省随裁片平移，相对裁片位置不变）

### 3. ADJUST_SHOULDER 肩宽调整

移动肩端点，调整肩宽至目标。

- **参数**
  - `目标`：尺寸引用（规格表.肩宽），必填
  - `联动袖窿`：布尔，默认 true（肩端外移需联动袖窿弧线）
- **前置条件**
  - 调整量在该品类允许范围内（落肩类超出范围应走 DROP_SHOULDER，不用本操作硬调）
- **操作步骤**
  1. 肩端点沿肩线延长方向移动至目标位置
  2. 袖窿弧线以新肩端点为端点按 H2 规则重连（不重拟合）
  3. 领圈端点保持不动，肩线中段按控制参数平滑过渡
  4. 袖窿弧长变化量登记 seam graph（袖山匹配依据）
- **校验规则**
  - 肩宽实测 = 目标值（容差 ±0.1cm）
  - 肩斜角度变化在原型 H1 允许范围内（动肩宽不许动版型基因）
  - 袖窿弧长变化已登记

### 4. ADJUST_NECKLINE 领口调整

领口开深（前/后中方向）与开宽（肩线方向）。

- **参数**
  - `前开深` / `后开深` / `开宽`：尺寸量，至少一项非零
  - `目标描述`：领型枚举引用（与部件方案.领一致时联动校验）
- **前置条件**
  - 开宽量 < 肩宽的 1/3（开宽过大已属款式结构变更，非调整）
- **操作步骤**
  1. 前/后领深点沿前/后中线移动指定量
  2. 领圈与肩线交点沿肩线内移开宽量
  3. 领圈弧线以新端点按 H2 规则重连
  4. 领圈弧长变化登记 seam graph（领片适配依据）
- **校验规则**
  - 领圈各端点新位置 = 指定值
  - 领圈弧长变化已登记
  - 领圈弧线与肩线交角在该领型合理范围内（告警级）

### 5. ADJUST_ARMHOLE_DEPTH 袖窿深调整

袖窿底点上/下移，改变袖窿深度（影响合体度与活动量的核心结构量）。

- **参数**
  - `调整量`：尺寸量（正=加深），必填
- **前置条件**
  - 加深后袖窿深在品类经验区间内（过深限制抬臂、过浅卡腋）
- **操作步骤**
  1. 袖窿底点沿侧缝方向移动调整量
  2. 袖窿弧线下段按 H2 规则重连
  3. 联动：袖肥/袖山按部件规则库的联动关系预登记（提示 S3 同步调整袖子）
  4. 袖窿弧长变化登记 seam graph
- **校验规则**
  - 袖窿深实测变化 = 调整量
  - 袖窿弧长变化已登记且已触发袖子联动检查
  - 侧缝总长变化与长度方向其他约束不冲突

## 二、省操作类

> 省量按省尖角 θ 记账。本类所有操作的公共校验：**总省量守恒**（S1 可见省 + 原型存量省 = 各去向之和）。

### 6. TRANSFER_DART 省转移

将省量从原省位转移到新省位（含转入分割线）。

- **参数**
  - `from`：省 ID，必填
  - `to`：目标位置（省位枚举或分割线 ID），必填
  - `ratio`：0–1，必填（1.0=全转，部分转移时原省保留剩余量）
- **前置条件**
  - from 省存在且省量 > 0
  - to 在合法转省点集合内（分割线为 to 时，该分割线必须经过省尖可达路径）
- **操作步骤**
  1. 计算转移省角 = from 省 θ × ratio
  2. 求关省旋转角：以省尖为轴，计算使 from 省两边重合的旋转角
  3. 从 to 位置向省尖剪开，纸样分待旋转块与固定块
  4. 待旋转块按转移比例对应的角度绕省尖旋转：原省按比例关闭，新位置按比例张开
  5. 重算受影响的缝合边弧长，差值登记 seam graph
  6. 更新省账户：from 省剩余量、新省（或分割线）获得量，记录血缘
- **校验规则**
  - 省量守恒：from 剩余 + 新位置获得 = from 原量（按 θ 计）
  - 经过省位的围度线总长不变（转省不改尺寸，只改合体度的位置）
  - 新省（如有）省尖指向符合部位惯例（前片省尖距 BP 2–4cm，告警级）

### 7. SPLIT_DART 省拆分

一个省拆为多个省（分散省量，避免单省过大、省尖明显）。

- **参数**
  - `from`：省 ID，必填
  - `targets`：目标省位列表及各自比例（比例和 = 1），必填
- **前置条件**
  - from 省 θ 大于"单省建议上限"（品类规则库给值，拆分才有意义）
- **操作步骤**
  1. 按 targets 比例将 from 省 θ 拆分为多份
  2. 对每个目标位置，依次执行 TRANSFER_DART 的第 2–5 步
  3. 原省关闭，登记各新省血缘
- **校验规则**
  - Σ各新省 θ = from 原 θ（无丢量）
  - 每个新省 θ 不超过单省建议上限（拆分的目的即在此）

### 8. MERGE_DARTS 省合并

多个省合并为一（通常配合分割线：两省并入一条公主线）。

- **参数**
  - `from`：省 ID 列表（≥2），必填
  - `to`：目标位置（省位或分割线 ID），必填
- **前置条件**
  - 各 from 省省尖可汇聚到同一结构点（如均指向 BP），或 to 为贯穿分割线
- **操作步骤**
  1. 计算合并省角 = Σ各 from 省 θ
  2. 按合并后的总角度执行转省步骤（同 TRANSFER_DART 第 2–5 步）
  3. 各原省关闭，新位置获得总量，逐笔登记血缘
- **校验规则**
  - 新位置获得量 = Σ各 from 省量
  - 合并后省口两侧弧度差 = 合并省角对应的几何量（分割线情形）

### 9. CLOSE_DART 消省

关闭省位，省量转为非省形态（松量/抽褶/分割线）。

- **参数**
  - `from`：省 ID，必填
  - `去向`：枚举（松量/抽褶/分割线 ID），必填
- **前置条件**
  - 去向=松量时：该部位廓形档位允许追加松量（不破坏合体度档位定义）
  - 去向=分割线时：分割线已存在（ADD_SLASH_LINE 已执行）
- **操作步骤**
  1. 去向=松量：关闭省，省口两侧拉平，省量并入该部位松量重新分配
  2. 去向=抽褶：关闭省，省口转为抽褶量登记（褶量 = 省口展开量）
  3. 去向=分割线：等价于 TRANSFER_DART(to=该分割线)
  4. 更新省账户与 seam graph
- **校验规则**
  - 省量去向登记完整（消省不是丢省，账必须平）
  - 去向=松量时，调整后该部位周长变化量 = 省口展平贡献量

### 10. ADD_DART 新增省

在原型无省处新增省（需求配平后存量不足的补量手段）。

- **参数**
  - `位置`：省位枚举 + 所属片，必填
  - `θ`：省角（引用配平方案的量值），必填
  - `省尖指向`：部位惯例枚举（BP/肩胛等），必填
- **前置条件**
  - 该位置无现存省（有则应走 TRANSFER/SPLIT）
  - θ 不超过单省建议上限
- **操作步骤**
  1. 在指定位置按惯例确定省中线与省尖点
  2. 以省尖为轴向两侧张开 θ 角，形成省口
  3. 相应围度线按省口量收短（周长减少 = 省量对应的宽度量）
  4. 登记新省与受影响缝合边
- **校验规则**
  - 新省 θ = 指定值
  - 该部位周长变化 = 省量对应宽度（加省即收量，账必须平）
  - 省尖指向符合部位惯例（告警级）

### 11. RESHAPE_DART 省形修正

不改变省量，只调整省的形态（省尖缩短、省位微调）。

- **参数**
  - `from`：省 ID，必填
  - `省尖偏移`：向量或"距 BP 距离"目标值，必填
- **前置条件**
  - from 省存在
- **操作步骤**
  1. 省尖点按偏移量移动，省口位置不变
  2. 两条省边以新省尖重连
- **校验规则**
  - 省角 θ 不变（本操作不动量）
  - 新省尖距 BP 在惯例区间（2–4cm，告警级）

## 三、分割线类

### 12. ADD_SLASH_LINE 新增分割线

按 S1 分割事实在裁片上破缝，一片变多片。

- **参数**
  - `位置`：S1 分割线 ID（含起点/路径/终点），必填
  - `类型`：分割线类型词典枚举（公主线/刀背缝/育克等），必填
  - `吸收省`：省分配引用（可空——装饰性破缝不吸省）
- **前置条件**
  - S1 分割事实中存在对应记录（禁止 S3 凭空加缝）
  - 贯穿路径两端均落在裁片边缘
- **操作步骤**
  1. 按起点→路径→终点生成分割线（经过关键结构点的按类型词典规则修形，如公主线过 BP 的凸度惯例）
  2. 裁片沿分割线断开为两片，分别命名（如前中/前侧）
  3. 若声明吸收省：执行省转移，省量转为分割线两侧弧度差
  4. seam graph 新增缝合边对偶，登记对位点与长度差
  5. 裁片数量清单 +1
- **校验规则**
  - 分割后两片边缘形状互补（缝合可行性）
  - 吸收省情形：两侧弧度差 = 吸收省角对应的几何量
  - seam graph 新边已登记，裁片数量账目更新

### 13. REMOVE_SLASH_LINE 取消分割线

合并相邻裁片，取消破缝。

- **参数**
  - `分割线`：分割线 ID，必填
  - `余量去向`：枚举（转省/转松量），必填——该缝吸收的省量不能凭空消失
- **前置条件**
  - 该分割线两侧裁片合并后仍符合门幅约束
- **操作步骤**
  1. 删除 seam graph 对应缝合边
  2. 两侧裁片合并，缝两侧弧度差按余量去向转为省或松量
  3. 裁片数量清单 −1
- **校验规则**
  - 原吸收省量完整转出（账平）
  - 合并后裁片宽度 ≤ 门幅（物料档案）

## 四、廓形摆量类

### 14. ADJUST_HEM 摆围调整

调整下摆围度至目标（H/A/X 廓形的关键尺寸）。

- **参数**
  - `目标`：尺寸引用（规格表.摆围），必填
  - `分配`：各缝分配比例（默认沿用 ADJUST_GIRTH 的分配规则）
- **前置条件**
  - 摆围与臀围的关系符合廓形定义（A 型摆>臀，X 型摆≈臀，告警级交叉检查）
- **操作步骤**
  1. 计算调整量并按分配比例摊到各缝
  2. 侧缝/前后中自下摆点起按调整量倾斜，与上部已有线条平滑相接
  3. 下摆线重连，登记缝合边变化
- **校验规则**
  - 摆围实测 = 目标值（容差 ±0.1cm）
  - 侧缝倾斜后仍与袖窿、腰围段平滑连续

### 15. ADD_FLARE 加放摆量/波浪

在指定部位增加非省形态的展开量（波浪摆、喇叭）。

- **参数**
  - `部位`：枚举（下摆/袖口/裙摆），必填
  - `展开量`：尺寸量或倍数，必填
  - `展开方式`：枚举（均布展开/定点展开）
- **前置条件**
  - 面料悬垂性支持（硬挺料大展开量 → 告警，参考物料档案）
- **操作步骤**
  1. 将该部位裁片按展开方式剪开展开（剪口数量按展开量分级）
  2. 外缘轮廓按展开后形状重连
  3. 摆围/袖口尺寸更新并登记
- **校验规则**
  - 展开后该部位实测增量 = 展开量
  - 与缝合对边的长度匹配关系已重新登记 seam graph

### 16. ADD_PLEAT 加褶裥

在指定位置加褶（箱褶/单向褶/工字褶），含褶量计算。

- **参数**
  - `位置`：裁片 + 部位，必填
  - `褶型`：枚举（箱褶/单向/工字/碎褶），必填
  - `褶量`：每个褶的展开量 × 褶数，必填
- **前置条件**
  - 面料硬挺度支持所选褶型（硬挺料忌碎褶，悬垂料忌箱褶——物料档案交叉检查，告警级）
- **操作步骤**
  1. 在褶位处将裁片展开褶量（每个褶 = 2×褶深）
  2. 展开区外缘重连，标注褶线、褶向剪口
  3. 该部位成衣尺寸不变、裁片尺寸增加 = 总褶量
- **校验规则**
  - 裁片增量 = Σ褶量（账平）
  - 成衣状态该部位尺寸仍 = 规格表值（褶是折叠量不是加肥量）

### 17. ADD_GATHER 加抽褶

在指定缝合边增加抽褶量。

- **参数**
  - `边`：缝合边 ID（seam graph 引用），必填
  - `抽褶倍数`：>1，必填
- **前置条件**
  - 面料悬垂性支持（硬挺料抽褶炸开 → 告警）
- **操作步骤**
  1. 该边长度按倍数展开
  2. seam graph 登记该边抽褶量与对边匹配关系（抽褶边长 = 对边长 × 倍数）
  3. 对位剪口按抽褶分布规则布置
- **校验规则**
  - 抽褶边长 / 对边长 = 指定倍数
  - 抽褶分布均匀性符合品类惯例（告警级）

## 五、肩与袖类

### 18. DROP_SHOULDER 落肩处理

肩端点外移、袖窿重构为落肩形态（装袖→落肩款的核心操作）。

- **参数**
  - `落肩量`：肩端外移量，必填
  - `袖窿下挖量`：必填（落肩必伴随袖窿加深）
- **前置条件**
  - 落肩量在品类经验区间内；袖型识别结果支持落肩（S1 部件清单）
- **操作步骤**
  1. 肩端点外移落肩量，袖窿底下挖指定量
  2. 袖窿弧线按新端点重构（落肩袖窿形态规则，非简单 H2 联动）
  3. 袖片基型对应调整：袖山高降低、袖肥增大（联动规则查部件规则库）
  4. 全部弧长变化登记 seam graph
- **校验规则**
  - 落肩后肩斜角仍在人体工学可行区间（告警级）
  - 袖山-袖窿匹配链已触发重算（吃势重新核对）

### 19. RAISE_SHOULDER 垫肩补偿

按垫肩厚度抬高肩端（正装品类）。

- **参数**
  - `垫肩厚度`：尺寸量，必填
- **前置条件**
  - 品类支持垫肩（西装/大衣类）
- **操作步骤**
  1. 肩端点上抬垫肩厚度（含面料压缩修正）
  2. 袖窿弧线上端按 H2 规则重连
  3. 袖山对应调整并登记
- **校验规则**
  - 肩端抬升量 = 垫肩厚度 × 压缩系数
  - 袖山-袖窿匹配已重新核对

### 20. ADJUST_CAP 袖山调整

调整袖山高，袖肥按互锁关系自动联动（二者只独立取一）。

- **参数**
  - `袖山高`：尺寸量（引用部件方案），必填——指定袖山高则袖肥联动，反之亦然
- **前置条件**
  - 新袖山高在"品类 × 廓形"经验区间内
  - 袖山基型已挂接（ATTACH_COMPONENT 已执行）
- **操作步骤**
  1. 袖山顶点按目标袖山高定位
  2. 袖肥按互锁关系计算并更新（袖山高↔袖肥反比联动，查部件规则库）
  3. 袖山弧线以新控制点按 H2 规则调整
  4. 袖山弧长与袖窿弧长重新核对，吃势按分配方案布置到剪口区段
- **校验规则**
  - 袖山弧长 − 袖窿弧长 ∈ 吃势 [硬边界]（越界拦截）
  - 前/后吃势分配比例 = 部件方案值（后 > 前）
  - 袖山高与袖肥组合满足互锁关系（改一必动另一）

### 21. ADJUST_CUFF 袖口调整

调整袖口尺寸与形态。

- **参数**
  - `目标`：尺寸量或引用，必填
  - `形态`：枚举（直筒/收口/喇叭/上克夫），必填
- **前置条件**
  - 袖长已确定（ADJUST_LENGTH 已执行）
- **操作步骤**
  1. 袖口两端点按目标尺寸定位
  2. 袖侧缝自袖口向袖肘方向平滑过渡
  3. 上克夫情形：袖口尺寸 = 腕围 + 松量，余量转褶或省并登记
- **校验规则**
  - 袖口实测 = 目标值
  - 上克夫情形：余量去向已登记（褶/省，账平）

### 22. CONVERT_SLEEVE_TYPE 袖型转换【复合】

装袖 ↔ 落肩/插肩的完整转换编排。

- **参数**
  - `目标袖型`：枚举（落肩/插肩），必填
  - `关键量`：按目标袖型的参数集（落肩量/插肩分割位置等）
- **前置条件**
  - S1 部件清单的袖型识别结果与目标一致（不一致先回 S1）
- **操作步骤**（固定编排）
  1. 目标=落肩：依次执行 DROP_SHOULDER → ADJUST_CAP → ASSIGN_EASE
  2. 目标=插肩：ADD_SLASH_LINE（袖窿分割）→ 袖片与衣身肩部重组 → ASSIGN_EASE
  3. 全程每步执行各自的校验规则
- **校验规则**
  - 编排中每个子操作的校验规则全部通过
  - 最终袖山-袖窿匹配链完整（无未配对的缝合边）

## 六、门襟贴边类

### 23. SET_CLOSURE 开合方式与叠门

设定门襟开合形式与叠门量，处理前中线结构。

- **参数**
  - `方式`：枚举（钉扣/拉链/暗扣/全开/半开），必填
  - `叠门量`：尺寸量（钉扣默认 = 纽扣直径 + 0.2），必填
  - `扣位`：扣数与首末扣位置（钉扣方式时必填）
- **前置条件**
  - 前片结构已确定（分割、省操作完成后执行）
- **操作步骤**
  1. 前中线按叠门量外放（左右片对称各放一半或按款式偏置）
  2. 按方式生成扣位/拉链位标记
  3. 联动挂面/贴边需求登记（通知 ADD_FACING）
- **校验规则**
  - 叠门量与方式匹配（拉链叠门 ≠ 钉扣叠门）
  - 扣位间距均匀且末扣距下摆安全量符合品类惯例（告警级）

### 24. ADD_FACING 贴边/挂面生成

为门襟、领口、下摆等边缘生成贴边结构（结构层，决定裁片形状）。

- **参数**
  - `部位`：枚举（门襟挂面/领口贴边/下摆贴边/袖口贴边），必填
  - `形式`：枚举（连裁/另裁），必填
  - `宽度`：尺寸量（按品类工艺规则），必填
- **前置条件**
  - 对应边缘结构已定案（领口调整、门襟设定已执行）
- **操作步骤**
  1. 连裁：沿边缘外放宽度并标注翻折线，裁片形状更新
  2. 另裁：按边缘形状复制生成贴边裁片，数量清单 +1
  3. 翻折线处按面料厚度加层叠补偿（物料档案）
  4. 派生裁片登记（贴边需衬时登记衬片需求）
- **校验规则**
  - 贴边宽度全程一致（容差 ±0.1cm）
  - 另裁贴边与对应边缘形状匹配（缝合边等长）

## 七、部件挂接类

### 25. ATTACH_COMPONENT 挂接部件基型

将部件基型（袖/领/袋）对接到衣身接口几何上，建立匹配关系。

- **参数**
  - `部件`：枚举（袖/领/袋盖等），必填
  - `基型`：部件基型 ID + 版本，必填
  - `接口`：seam graph 边引用（袖→袖窿、领→领圈），必填
- **前置条件**
  - 接口几何已定案（衣身的领圈/袖窿不再变动——部件永远后于接口）
  - 基型与衣身原型配套关系有效（标定记录可查）
- **操作步骤**
  1. 读取接口弧长（前/后分段）
  2. 部件基型按接口弧长定位基准：袖山弧长 = 袖窿弧长 + 吃势；领下口 = 领圈弧长
  3. 建立对位点映射（肩点、前后腋点、领圈肩点等）
  4. seam graph 写入缝合边对偶
- **校验规则**
  - 部件基准弧长与接口弧长的差 = 声明的吃势/缩量（账平）
  - 对位点一一对应，无悬空

### 26. ADD_POCKET 加口袋

按部件方案在指定位置生成口袋结构。

- **参数**
  - `类型`：枚举（贴袋/插袋/开线袋），必填
  - `位置`：裁片 + 定位点（引用部位比例或规格表），必填
  - `规格`：袋口大、袋深，必填
- **前置条件**
  - 所在裁片已定案（口袋不跨未定分割缝；对条格面料已声明纱向约束）
- **操作步骤**
  1. 贴袋：生成袋片裁片 + 位置标记 + 袋口加固位
  2. 插袋：在侧缝/分割缝上登记袋口区段，生成袋布（派生裁片 ×2）
  3. 开线袋：衣身开袋位剪口 + 嵌条 + 袋布（派生裁片）
  4. 数量清单与 seam graph 更新
- **校验规则**
  - 袋口大满足手部通过最小值（品类惯例，告警级）
  - 插袋/开线袋的袋布与袋口匹配，裁片数量账目更新

### 27. ASSIGN_EASE 吃势登记

将缝合两边的长度差按分配方案布置为吃势（不写几何，只写 seam graph 账）。

- **参数**
  - `边`：seam graph 缝合边 ID，必填
  - `吃势量`：尺寸量（引用部件方案），必填
  - `分配`：各区段比例（比例和 = 1，如前 0.4/后 0.6），必填
- **前置条件**
  - 该边两边弧长已最终确定（ADJUST_CAP、ATTACH_COMPONENT 已执行）
  - 吃势量在部件规则库四层参数的硬边界内（软边界外告警）
- **操作步骤**
  1. 核对两边弧长差 = 吃势量（不符即失败，不做任何抹平）
  2. 按分配比例将吃势量布置到对位剪口划分的区段
  3. seam graph 写入区段吃势明细
- **校验规则**
  - Σ区段吃势 = 总吃势量
  - 吃势布置在剪口区段内（禁止均匀铺满全弧——前后片对位必错）
  - 针织类目吃势 ≤ 1.5cm（部件规则库断言）
