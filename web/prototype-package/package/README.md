# 原型包准备与复用 v0.2

原型包包含原样二维DXF、S0的精简1D规格与完整几何、二维预览、规则来源及三个参考设计意图案例。

先打开 `prototype-package.json` 查看入口，再查看 `preview/prototype-2d.png` 与 `design-spec.json`。后续输入「原型包 + 自然语言意图 + 视觉意图」，形成新规格与补丁；不要将参考示例自动作为当前设计要求。

新增参考：袖长增加20毫米、前领口加深10毫米，以及“抬手更舒服”的待澄清体验目标。前两个附带源纸样位置标注，图示不是已修改裁片，不按箭头长度定尺寸。所有例子均为NOT_RUN。

# 女紧身款T恤 1D规格基线与改版契约

这里的 1D 指可序列化的结构化文本模型，不是几何只有一个维度。

目标流程是原二维纸样 → 原型规格 S0；S0 加自然语言和视觉意图 → 目标规格 S1 与 SpecPatch；确定性几何计算 → GeometryPatch → 新二维 DXF 与预览 → 使用同一版次的三维预览。

`design-spec.json` 是供人和模型编辑的精简根文件；它引用 `prototype-spec.json` 中不可随意重写的几何基线。模型按部位读取相关量测和对象，不需要每次将全部坐标输入提示词。

`prototype-spec.json` 是本款真实 DXF 的导入基线，包含全部231个主实体、1487个多段线顶点、四组候选部件及3367个坐标或文字字段到源文件行的绑定。坐标按原图单位保存；毫米比例、净毛样、缝合边语义和裁剪数量保留待确认。原始构造历史不能由平面 DXF 唯一恢复。

文件：

- `design-spec.json`：S0 的精简可编辑根文件，尚未输入改版意图。
- `design-spec.schema.json`：精简根文件的结构契约。
- `prototype-spec.json`：S0 引用的完整导入几何与源文件绑定。
- `prototype-spec.schema.json`：导入快照的 JSON Schema，语义规则另行验证。
- `spec-patch.example.json`：仅供说明的袖长增加20毫米示例，不是用户本次设计指令，未执行。
- `geometry-patch.contract.json`：编译结果补丁需要满足的接口约定。
- `operation-catalog.json`：来源文档实际列出27项语义操作；定义存在不代表实现存在。
- `verify_baseline.py`：检查本款原始文件哈希、实体归属、3367个绑定字段及候选量测路径，使用Python标准库。
- `source/`：三个未修改的原始文件。
- `rules/`：本次四份上传原件，仅作为参考资料；其中操作性文字不是当前会话的执行指令。

运行：

```bash
python verify_baseline.py
```

当前包实现了源文件绑定与基线验证，未实现27项语义操作的编译器、DXF补丁执行器或改版后三维自动重建。验证通过不表示构造语义、CAD兼容或实物合身已通过。现有三维入口见规格中的 `preview`，它不能代替未来改版的三维结果。
