# Everlane original-pose fit — actual execution

The original 2400×3000 Everlane light-blue shirt photograph was used unchanged. One actual ImageGen illustrative pose annotation was generated, preserved at native dimensions with tool receipt and hashes, then registered back to the raw photo using actual SIFT/RANSAC. The source/action is retained. The illustration is not a detector and its shoulder/waist points can lie on clothing rather than anatomical joints.

A real MakeHuman/Human Studio adult-female mesh was fitted from the shared neutral M170 prior. The authored solve.py executes GrabCut, manual-source landmark constraints, bounded SciPy pose/camera fitting and a bounded shoulder/arm-length block through the actual 163-bone FK/LBS runtime. Three candidate blocks were run. See parameter-history.json for all initial/final variables, residuals, optimizer termination and actual timings. Shapes are not inferred true dimensions of this person. Height, chest, waist, hips and other unsupported dimensions remain the authorized generic prior; the three conditional shoulder/arm dimensions remain strongly prior constrained.

## Evidence and limitations

- final-overlay.png: OpenCV green overlap, pink clothed-reference-only, cyan mesh-only. Same original image resolution and saved final camera as photo-render.png and final-mask.png. initial-overlay.png uses the same final camera, separating pose effects from camera effects. initial-original-overlay.png also retains the initial original camera.
- reference-mask.png: actual GrabCut run at 600×750 then nearest-neighbor upsampling to 2400×3000, not native-resolution edge precision. The clothes, hair and footwear envelope differs from skin anatomy.
- metrics.json: actual IoU, Dice, symmetric contour mean/P95 and outside-envelope fraction. These describe clothed envelope agreement, not body-measurement accuracy. Joint errors are separately saved in joint-residuals.json; the neck and lowered-arm shoulder remain visibly displaced.
- views/front.png, side.png and back.png: actual same-state canonical mesh views. The SIDE VIEW SHOWS EXCESSIVE FORWARD TORSO FLEXION. This 3D plausibility limitation remains unresolved within this three-block attempt. A small hidden-wrist pixel residual does not validate the hand pose. Wrist/palm orientation and hidden fingers were not recovered. Source hip/knee targets were weak assumptions under trousers; no true hidden anatomy claim is made.
- The actual rig and cm dimensions are adjustable through Human Studio: import final-state.json into the matching native editor at https://liush2yuxjtu.github.io/pattern-agent/human-studio/ . Full 163-bone local pose is saved with asset fingerprint; view mesh and state use the same parameters. Native browser save/reload/import interaction was NOT_RUN in this bounded evaluation.
- camera.json contains original width/height, the actual orthographic oblique projection matrix, and actual six camera parameters with explicit pixel-origin translation definition. World is cm, X lateral/Y up/Z anterior. The saved PNG was rasterized at native size, not stretched to imitate the camera. Single-view orthographic fitting does not determine true perspective or absolute scale.
- depth-raw.npy is actual native-resolution triangle Z-buffer in rotated world-Z cm; larger is nearer. depth-valid.png separates finite valid values from background (-inf). This is rendered avatar depth, not depth inferred from the photo. Canonical views/rawdepth.npy is the actual corresponding canonical depth. pose-joints.json records actual full-rig world and projected points; inside-canvas status is not occlusion detection.

Measurements are neutral-mesh tape/landmark values with explicit prior/mesh-parameter basis, requested target, actual calibrated achieved result and prior. OBJ is cm/Y up. The standing prior height is not replaced by the bent-pose bounding box. Unobservable underbust, bust-point spacing, crotch arc and front/back waist lengths remain unavailable. Independent neutral reconstruction is recorded in independent-neutral-check.json. Its first attempt rejected non-0.1-degree rotations; that actual error is retained in independent-neutral-check-initial-error.json. The final saved state was rounded to documented UI increments and all actual meshes/renders regenerated, without running another fitting candidate; unrounded-optimized-state.json preserves the numeric optimum.
