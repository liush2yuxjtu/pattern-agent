## Executed

One actual Image Gen edit received only the original image and requested the original lowered-arm action with dot/line guidance. Native output is images/pose.png, unchanged native 1086 × 1448 pixels, with receipt, original input hashes and native file retained. Generated guide is illustrative. SIFT/RANSAC approximate native-to-original registration has 647 inliers and mean inlier error 0.67 px; transform and native/raw points are in imagegen-registration.json. The neck dot is too low anatomically; hidden pelvis/knees are guesses. Coarse arm directions agree with the original. Original manual approximate shoulder/elbow/wrist cues take precedence; no invented hidden wrist is treated as observation. Image-right wrist is partially obscured by clutch and its rotation/contact cannot be recovered.

Independent solver fit.py starts from shared neutral state, using real MakeHuman morph calibration, 163-bone FK and linear blend skinning through generic Runtime. Two front/oblique camera starts compare camera and arm/leg pose; a third block jointly tries supported arm-length changes with prior penalties. This is not a reused case solver. Numerical block time: 3.701 s, excluding actual rasterization and Image Gen waiting. Dimensions and full pose are quantized to editor 0.1 cm/degrees, then ALL final geometry is rebuilt. Conditional arm lengths round back to the original 29/23 cm. Spine/root angles remain zero. Source camera is an oblique orthographic approximation, not a recovered physical camera; camera obliqueness can absorb anatomy/landmark error.

final-state.json, neutral.obj and posed.obj use cm and Y up. Mesh is the actual 13,380-vertex / 26,756-face MakeHuman anatomy, not proxy geometry. views/ is generated by Runtime.save from exactly the same dimensions/full pose, changing only canonical cameras. Actual 800 × 1067 source render is photo-render.png, never stretched. camera.json includes world_to_pixel_homogeneous 3×4, six generic camera values and resolution. projected-pose.json is actual FK projection, with in-frame flags and UNKNOWN occlusion. rawdepth.npy is real rasterized rotated-world-Z cm (larger nearer), background -inf, with independent validity mask and false-colour depth preview. It describes mannequin geometry, not observed person's depth.

Reference segmentation uses original-resolution manually drawn silhouette polygon seeds plus OpenCV GrabCut. Seeds, method and limitations are saved. Hair, garment, clutch and shoes are included; skirt outline cannot constrain naked hips/legs. Initial and final OpenCV overlays/metrics use the same reference bytes and resolution; an additional initial mesh render uses the frozen FINAL camera to separate camera improvement. Green is overlap, pink reference-only, cyan model-only.

Whole-clothed-silhouette IoU initial 0.5384, initial at final camera 0.5201, final 0.7342. These are descriptive, not a grade or person-size accuracy. Broad skirt, hair and shoes necessarily differ from the naked mesh; shoulders/arms have visible envelope residuals. No claim is made that every original critical region passes acceptance.

## Verification and limits

Frozen-skill independent inspect_human_state.py reconstructs neutral mesh from matching asset and verifies tape/landmark dimensions: maximum error about 0.000041 cm, a model numerical tolerance only. evidence/replay-audit.json checks actual OBJ/FK replay, camera projection, state equality, topology, finite nonempty depth and limited hand-surface proximity. Bone segment lengths are separately in bone-lengths.json; these are not surface tape lengths.

Actual front/side/back images were visually inspected. Arms are lowered and nearly straight, no forced crossed or raised action. Clutch grasp is weakly curled prior fingers; bag contact is NOT solved. The standing-relaxed diagnostic reports one accumulated spine/neck-chain tilt warning even though local spine/neck rotations remain neutral; retained for review, not suppressed. The template's cervical chain and hidden depth are not established by this photo. Vertex proximity is NOT triangle penetration/collision validation. Full skin collision, contact, tissue, balance and cloth simulation: NOT_RUN. Severe overlap-free geometry is not certified. Canonical hidden views are hypotheses, not independent evidence.

Measurements JSON/CSV distinguish prior / mesh_parameter / unavailable. Mesh-checking does not upgrade priors to real-person measurements. Underbust, bust point distance, shoulder slope, waist lengths and crotch arc remain null. M170 scale differs from published model height; all values are conditional on this explicit scale assumption, with no invented statistical interval.

viewer.html includes a copied unmodified Human Studio editor linked to this final state, complete adjustable centimetre/morph/163-bone controls, save/import/export and canonical buttons. Serve directory via HTTP. Default saved state is quantized and matched to asset. Browser interaction/mobile/save-reload tests in this run: NOT_RUN; no claim of new UI testing. Changing editor state invalidates frozen evidence above.

Full six independent garment images: NOT_RUN, outside requested pose-fit branch. No private grader, heldout oracle annotations or other run outputs were read. No self-grades. Timing/token telemetry unavailable at run level: null.

Reproduce: from repository root execute `OPENBLAS_NUM_THREADS=1 python <outputs>/fit.py`, then frozen-skill inspect_human_state.py and audit_pose_geometry.py commands recorded in TRACE.md, then `python <outputs>/finalize.py`.
