# 几何证据合同

只执行当前请求涉及的分支。每份证据保存实际输入、参数、输出路径与哈希，
让另一位执行者能从文件复算结论；不要把未运行项目标为通过。

## 状态、网格与单位

用 `inspect_human_state.py --asset-json` 对匹配指纹的资源独立重建 neutral/rest
网格，重算 tape paths 和 landmarks；缺少资源的结构检查不算独立复量。
保留目标、实测、残差、完整姿态与 morphWeights。对于不可达目标，报告最近结果。
posed 表面用于姿态与导出核验，不能拿弯膝后的高度或胸部斜截面替代中性尺寸。
读取真实 OBJ 顶点和 GLB 节点变换后的世界顶点，核对对应姿态与尺度：OBJ cm，GLB m。
以数值边界或对应点证明 0.01 比例，不能仅检查文件扩展名或 metadata 中的单位标签。
从 getGeometry 的 compact posed 表面建网格时通过 bodyVertexIds 重映射原始 indices。

## 相机、姿态与深度

Human Studio JSON 不保存相机，且尺寸/预设会重新取景。完成体形与姿态后，在独立
渲染器保存并复用 view/projection 矩阵、投影类型、坐标轴/单位、近远面、画幅与像素约定。
同时记录状态、资源、mesh 和 pose 的标识/哈希。若重取相机，作为另一套协议。

用这套相机投影实际 world joints，保存 joint 名称、世界坐标、像素坐标和可见性。
允许屏外或遮挡关节，但分别标记；只画有效点和拓扑正确的骨架边。
由三角形光栅化得到 z-buffer 与 silhouette。保存未经着色的深度数据和布尔有效掩膜，
明确 depth 是相机轴向距离、射线距离还是 NDC，相机前向/近远颜色方向及数值单位。
背景使用单独掩膜或明确的无效值，不混入有效深度归一化。
检查有效像素非空且有限、深度落在声明范围、有效掩膜与表面投影一致。
姿态、深度与叠加图使用相同网格/姿态、相机和分辨率。它们与自由生成的穿衣照片
没有天然逐像素对应关系；若缺少真实配准，只报告渲染几何的一致性。

## 拟合与独立复核

读取并冻结真实提供的参考及 camera；保存哈希，避免通过改参考、评价区域、分辨率
或重新取景制造改进。在真实解剖表面上优化可辨识的 shape/pose 参数，保存运行代码、
初始/最终状态与实际网格。用同一相机光栅化两份网格，输出每视角的 initial/final
mask、叠加及指标。先做小分辨率搜索时，最后回到原定评价分辨率重算两者。

从最终保存的参数/资源独立复量 neutral tape paths 与 landmarks，核对最终实测尺寸和残差；
截面周长另列定义，不拿它冒充模型带尺。将参数、实测、指标和图像绑定到同一最终版本。
保留最弱视角与退步，不把衣物外轮廓当裸身轮廓。若参考来自同一个人体生成过程，
即使拟合改善且独立复算通过，也只能声称几何/生成视图内部一致性，不能声称真实人体测量准确。
