# Teagan · 二维与三维纸样工作室

直接运行固定版本 `@freesewing/teagan@4.10.2`（Joost De Cock，MIT），以原始制版算法及命名点、贝塞尔路径、缝份为基准。基础、宽松和短身是同一个真实母版的参数变体。原型记录及哈希位于 dist/prototypes，源代码和量体均可复核。

默认并列呈现真实 2D SVG 和普通材质的同源 3D 组装，热图默认关闭。前后半片依源母版对折展开成完整前后片，再用同一2D轮廓三角化生成两袖；2D顶点与3D顶点保留一一对应关系。三维按肩缝、侧缝及袖窿-袖山边界建立示意组装；展开滑杆只改变同一网格顶点的位置。WebAssembly实际执行单位转换、规格差量及组装到展开的线性插值。

可以调整衣长差量、胸围松量、袖侧缝差量及领口展开比例，查看真实点位差量，叠加原始母版，选择裁片联动高亮，并导出毫米1:1 SVG、含曲线及配缝图的JSON、规格补丁和米单位OBJ。

版师工具：命名点与贝塞尔控制柄拖动及毫米坐标输入，网格吸附与轴向约束，线/曲线转换，精确细分，直线量尺与曲线弧长，逐边缝份与折边派生，剪口、对位剪口、布纹与裁剪数量，裁片缩放及独立纸面排版。走缝支持进度与 B 边反向，设计吃势与容差独立保存；固定端点配缝优化只调整控制柄，无解时拒绝。手工几何变更作为有序操作保留，不被参数重算无声覆盖。

修改支持撤销/重做、本机版本、工作草稿自动保存、工程JSON导入导出以及精确重放。另提供 SVG、毫米 DXF 和真正的 A4 1:1 拼页打印（可保存 PDF）。DXF是普通二维交换格式，并非AAMA/ASTM或某个CAD的原生工程。

几何检查涵盖有限坐标、净样闭合、自交、零长度边、对折轴、裁剪轮廓、剪口、元数据与配缝误差；错误几何会拒绝提交，配缝不达标保留为FAIL草稿。缝份采用FreeSewing原始曲线偏移；接角交叉时用Clipper非零填充布尔整理，曲线离散容差0.03mm、整数分辨率0.0001mm，无法得到单一轮廓则拒绝修改。

`npm run build` 编译WAT及浏览器应用；`npm run verify` 检查原始母版、规格修改和同源2D/3D；`npm run verify:expert` 检查版师工具与负例。验收记录位于 dist/verification/expert-report.json，包含实际浏览器流程及构建资产SHA-256。

限制：量体为明确的演示输入，非用户实测。3D是由实际裁片构成的约束组装预览，提供当前网格的几何形变检查，尚未做布料物理仿真、人体碰撞或真人试穿；不应将组装预览当作生产批准。袖山配缝差量如实显示。领口保留开口，未另生成领条。实际浏览器使用环境已安装的Chromium/Playwright，通过文件路由加载完全相同的dist字节（原生浏览器连接服务不可达，托管预览中继超时）。已执行1440×960桌面、390×844手机、指针拖动、下载、保存重开及实际PDF打印；是否通过以验收JSON为准。上线由Sites返回部署状态另行确认。

本轮覆盖Teagan T恤的二维改版闭环，未实现完整工业CAD的省道转移、任意结构切分、尺码放码矩阵、自动排料、工业原生CAD/CAM往返，亦不声明专业版师或工厂已签核。


曲线专项复核：旧版配缝仅约束总弧长，可能破坏同一曲线接点的G1切线连续性。新优化器g1-length-v2固定所有曲段端点，使用共同接点方向和正控制柄长度缩放，在G1约束下求目标弧长。检查新增内部零导数点及0.1度G1工程门槛；未通过的平滑度作为FAIL草稿保留，阻止“长度达标即全部通过”的误判。G1不等于G2或实物合身。

工程schema维持pattern-expert-project/1，增加engineVersion:2及逐操作algorithm标记。旧工程未标记的matchSeam按legacy-chord-v1重放，原端点与控制柄保持；新检查可将旧折角标为FAIL，只有显式新优化才追加修正，不重写旧历史。SVG坐标由2位小数升级为6位，减少表示层舍入误差。

复核命令：node scripts/export-curve-audit.mjs → python3 scripts/verify-curves.py → python3 scripts/render-curve-audit.py。独立Python使用幂基求值、SciPy自适应积分及导数根检查，不调用应用的Bernstein/Gauss实现。专项数据、方法和图在dist/verification/curve-audit.html及curve-audit.json；保留旧算法失败夹角作为对照。

人体与形变热图：离线随站点分发 MakeHuman hm08 基础人体的 CC0 图形资产（不是 MakeHuman AGPL 程序代码）。固定上游 revision `3c701a8e52f09e69922e8b598d23be2d7dfc49e3`，原始 OBJ、CC0 完整许可及提取后的 JSON 位于 dist/models；prepare-human.py 只提取 body 组并三角化。运行时按原始胸部水平截面周长校准为 96cm、身高约175cm，再调整双臂显示姿态。此参考人体不是个人扫描，也不驱动衣片碰撞。

热图逐三角形比较二维净样采样网格与当前显示的三维顶点，使用 F=Ds·Dm⁻¹，WebAssembly 求 FᵀF 的特征值/主伸长。主拉伸为 (σ−1)×100%，面积变化为 (σ₁σ₂−1)×100%；剪切按当前布纹与垂直方向映射后的夹角计算。2D/3D 使用同一逐面数值和固定发散色标，超色标面积如实报告，原始数值不裁剪；选择裁片的统计按二维参考面积加权。完全展开时重算，几何拉伸应回到零。颜色不代表面料应力或身体压力。较大的数值会暴露当前示意组装的失真，不能直接解释为实物衣服拉伸。

网格改为9mm规则单元与原始净样采样轮廓的Clipper交集，再逐单元三角化，避免原长扇形三角网格，再以保持轮廓的对角线翻转改善边界薄片面。曲线本身及所有编辑操作保持原定义；三维边界使用每曲段22步的采样近似，交点坐标整数精度0.00001mm。

`npm run verify:deformation` 运行已知拉伸/压缩/刚体变换、退化负例、3种母版的组装/中间态/完全展开及人体比例检查，再由独立NumPy矩阵求逆和3×2 SVD复核所有导出的实例（数量见验收JSON）。检查脚本和浏览器截图在工作目录；本次验收摘要附于既有expert-report.json，应用可导出逐面形变JSON（含二维参考、当前三维顶点、三角索引、单位和人体来源）。

高值专项复核：旧版51,401实例验收只证明几何公式与独立SVD一致，没有证明网格峰值收敛，更未证明物理合理性。固定旧提交c8c4372的基础款峰值样例在scripts/fixtures/heat-legacy-high-values.json；后片峰值595.75%，袖片570.24%，袖片极端三角形最小高约0.0019mm，旧袖口定位还把56.43mm的腋下端点弦长拉长到约143.70mm。

source-length-assembly-v2保留二维源点与路径，采用弧长参数化的椭圆衣身与袖口，肩部深度过渡由真实肩线至袖窿高度决定；袖口摆位求解纸样中心线长度及腋下端点弦长，显示人体手臂跟随该角度。无解时明确记录失败，不擅自放宽长度约束。网格采用9mm单元、保留边界的对角线翻转；9mm与独立4.5mm网格对照，峰值变化门槛5个百分点、参考面积均值变化门槛0.5个百分点。这是数值稳定性门槛，不是面料允许应变。

`npm run verify:heat-values` 验证弧长映射单位速度、真实衣身/袖口局部长度、腋下端点距离、无解负例和3个变体的网格细化；Python独立SVD重算旧峰值、SciPy积分复核弧长及独立重建袖口端点约束。UI可定位极值并显示三角形最小角；最长边/对应高>50标为网格敏感，原始值始终保留。即使数值验证通过，clothSimulation/bodyCollision/physicalFit仍为NOT_RUN，physicalInterpretation为NOT_VALIDATED，剩余局部约70–82%的几何形变不能用作真实布料拉伸或合身结论。

参考人体在单独背景层绘制，热图衣片随后绘制，避免未求解的人体穿插遮住诊断数值。此合成不代表碰撞已解决或衣片真实贴合人体；导出中明确rendering=background-reference-no-contact-occlusion。几何坐标与逐三角形数值不受绘制顺序影响。

多视图选择：顶部「二维纸样 / 三维实体 / 三维热图」是三个独立开关，支持七种非空组合，含普通三维与热图三维同时对照。每次载入默认开启paper+model，mode=solid；heat关闭，热图渲染器按需创建，不从草稿或上次选择自动恢复。两个三维视图共用同一裁片网格与展开状态，使用独立画布、相机和旋转控制；热图以可调强度叠加在实体上，普通三维不会继承热图颜色。二维热图也需另行手动勾选。编辑、裁片选择及展开进度在所选视图间联动；至少保留一个视图，手机按选择纵向排布。

window.patternStudio.setViews(['paper','model','heat']) 可设置任意组合；旧setView('split'|'2d'|'3d')入口仍支持。视图只是本次会话的显示偏好，不写入纸样工程或修改任何点边。

## 当前状态管理

`src/studio-state.mjs` 将求解任务和尺寸草稿作为独立生命周期管理。求解状态为 `IDLE → SOLVING → READY / ERROR / UNAVAILABLE`；`READY` 表示结果属于当前纸样，可以继续查看其几何检查的 `PASS` 或 `FAIL`，不把有效的失败报告混同为计算故障。

每个任务绑定纸样修订号并独占一个 Worker。新修订取消旧任务；迟到的结果、进度或错误不能接管新任务。显示方式、四个视图开关、镜头与展开预览独立于求解；切换线框不再重启计算。显示中断恢复也不会修改纸样或启动求解。

尺寸输入按字段合并，保存、工程导出及后续修改会先提交待应用的尺寸。撤销优先取消当前草稿；替换工程在校验成功后才清理旧输入。异步文件读取带选择顺序和编辑版本检查，不能覆盖读取期间的新修改。纸样更新会取消旧拖动，移除指向已删除命名点的量尺引用。

求解中、计算失败或尺寸待应用时，不显示旧热图读数，不允许导出当前三维结果。失败可显式重试；人体资产重试与几何求解分开处理。几何报告、诊断、状态和调试数据均以独立快照读取。

浏览器可调用 `patternStudio.getStateMachine()` 查看修订、草稿、任务、各窗口和不变量；`patternStudio.getDiagnosticLog()` 保留实际状态转换及迟到事件。`npm run verify:state` 检查生命周期和 5,000 次确定性乱序事件；`npm run verify:state-browser` 重放真实界面、故障注入、异步导入和真实 Worker 重算。四视图、穿着与折角验收仍分别由原有检查脚本验证。
