# 静态几何穿着验证

当前页面从 FreeSewing Teagan 4.10.2 的真实净样生成同源网格。前、后片对折展开，左右袖片保留自己的二维参考坐标。人体使用仓库内的 MakeHuman hm08 CC0 模型，演示胸围 960 mm、身高 1750 mm。求解不会修改源纸样、缩放净样或缩小人体。

三维初值先作刚性平移，再迭代求解边长、三角形应变、衣片内部与跨缝弯曲、镜像、双向接缝和人体接触约束。接触目标间隙为 4 mm；此外检查面中心并修正接触。短边重网格允许相对采样净样最多 0.01 mm 的边界误差；源贝塞尔曲线保持不变。三款母版的实测最大边界误差为 0.00758 mm。该容差与人体交叉、配缝验收分别检查。

验收使用实际求解后的衣片及实际渲染人体顶点，检查所有顶点、边中点和面中心是否在人体内部；对全部衣片三角面作空间宽相位及三角形分离轴交叉检测。指定配缝的双向点到折线距离每段采样 9 点，最大间隙须 ≤ 1 mm。领口、下摆和袖口须在投影中包住对应部位；腰部截面还检查 36 个射线方向。人体与衣服共用深度缓冲，不清除深度把衣服强制画到前面。

`npm run bake:fits` 从源纸样重新求解三款母版并生成预计算结果。预计算数据只在源点、缝边、人体版本、胸围及姿态精确匹配时使用。编辑纸样会在 Worker 中重新求解，撤销此前的通过状态；连续编辑会取消旧任务。展开预览不显示穿着通过。

`npm run verify:wear` 重新导出渲染网格，使用独立 Python/NumPy 的三个斜射线奇偶检测及三角形分离轴检测复核。原始未处理的组装必须被负例检查拒绝。报告输出到 `/tmp/pattern-wear-audit/wear-report.json`。发布的完整复核与浏览器结果位于 `dist/verification/wear-report.json`。

`python3 scripts/verify-wear-browser.py` 检查三款母版、真实深度渲染、下载、Worker 重算和取消过期任务。`python3 scripts/verify-browser.py` 检查二维、普通三维、热图七种非空视图组合、编辑与移动端。浏览器脚本需要已安装的 Chromium、Python Playwright 和 Pillow；通过文件路由加载实际 dist 字节，无需开发服务器。

热图始终使用当前三维相对二维净样的形变梯度，不裁剪原始数值。几何通过仅说明当前静态演示人体上的位置、接缝及开口通过上述检查。面料力学、压力、个人合体、连续运动与自碰撞未校准；不能将热图直接视为真实面料应力。

## 圆顺装袖修正

默认工程保存 `g1-zero-ease-v1` 袖山修顺版本，在原始 Teagan 之上固定所有缝线端点，以已有 G1 优化器微调控制柄，使袖山与袖窿达到零吃势。前后衣片、袖口、袖底缝长度及裁片端点保持原值。页面可关闭「袖山修顺」对照原始净样，原始/修顺结果均使用相同的新三维求解器。旧工程缺少该字段时按原曲线回放；无手工编辑的旧本机草稿会记录一次可撤销的默认修顺升级，明确关闭后的选择会保留。

三维弯曲使用相邻三角形对角距离正则化，并包含跨配缝耦合。镜像约束只针对本页严格对称的演示人体和同源袖片。它们不是校准后的面料弯曲刚度。缓存格式和 Worker 资源版本已更新，旧缓存不得绕过新检查。

袖山平顺检查从源弧长 2.5+5k mm 均匀采样，取实际袖山最高35%，排除腋下。使用未平滑的真实相邻三角面，要求法平面夹角 P95 ≤30°，向内余切反折角最大≤45°，两袖同源顶点镜像误差≤0.5 mm。袖片内部另外检查P95≤25°、最大≤45°，排除袖底缝15 mm邻域的设计折转；求解使用真实二面角梯度限制异常尖折，保留二维净样。这个阈值是本次无结构装袖预览的工程目标，不能用于否定有意的箱形落肩设计。`scripts/verify-sleeve-quality.py` 独立用 NumPy 和 SciPy 复核真实几何、源曲线弧长与切向，并拒绝第8版虽通过穿透检查但存在尖折的袖子。

参考：FreeSewing Teagan 官方设计与选项说明、Brian 五段袖山构造；In the Folds 的 Cartwright 装袖与 Marden 落肩对照。Teagan4.10.2源码采用零袖山吃势，不能通过任意加吃势来制造圆肩。
