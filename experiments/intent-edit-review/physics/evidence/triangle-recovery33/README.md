## 完整网格恢复方法

recover.mjs 读取实际 WASM configure_cloth/finalize_seams 的焊接逆质量，仅在测试子类中替换 gather：VF+EE关闭，完整网格 gatherTriangleContacts 注入原 MeshContact Jacobi 回调。既有 inverseMass 权重、平均提案、**每PASS完整实际位移 cap=0.5mm**、previous+=0.8实际位移、snapshot refit/requery 保留。h=1mm、严格相交 epsilon=1e-6m不变。

A/B按face index稳定排序；初始已经交错且无历史可行侧时用现有模块的固定+B normal；shared1用实际共点锚，不生成重复缝点。history固定为run33准备末态，没有隐藏 pair cache。只执行40轮，不无限追加。没有施加人体、膜、铰链或重力响应。每一轮都运行在完整7186面网格上，不用孤立六点 fixture 替代整网。

在累计1/4/10/40轮，将焊接坐标传播回所有源码别名，生成单独的 work checkpoint。audit.py 使用独立严格全部三角面 oracle、真实人体顶点/边中点/面中心采样、布边→人体和人体边→布面双向完整检查、原数字穿臂 oracle 和拓扑/来源/缝隙检查。保持原验收条件，不调用接触响应代码作碰撞裁决。
