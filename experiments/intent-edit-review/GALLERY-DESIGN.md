# 案例库应用界面

本轮修复在线实验入口像文档的问题。仓库 README 继续集中索引整个实验；在线默认界面
改为五个真实案例的可操作画廊，说明正文放入同页“实验说明”。采用现有原生静态HTML、
WebGL/CPU查看器和自包含文件，不新增框架、后台或假生成按钮。

## 视觉与组件

布局参考为本轮 Image Gen 的完整应用截图；验收证据保存其原图与真实浏览器对照。
白底 `#ffffff`，深绿 `#285347`，文字 `#1f2925`，边线 `#d3dbd7`，预览底 `#eef1f3`。
桌面左侧约205px应用导航，主区域为标题、搜索/筛选/视图工具栏和三列五个案例。
1280px及以下改为两列；760px及以下导航移到顶部；480px及以下案例单列。
标题34px，卡片标题22px，控件14–16px，内容15px，卡片边线1px、圆角7px。

允许的默认文案：Pattern Agent、案例库、原型输入、实验说明、GitHub README、项目文档、
设计案例、从原型开始比较四个已验证的改版、搜索设计意图、全部5、可查看缝合2、
待缝合配置3、三维示意、二维纸样；以及原型、袖子加长、衣身缩短、袖口加宽、前领加深
及其真实摘要、状态、打开实验。页脚始终说明U未标定、静态几何和试穿范围。
导航采用同一套约21px细线图标，按钮均为真实原生控件。

## 实际操作

- 设计意图搜索与缝合状态筛选可以组合；空结果可清除筛选恢复五个案例。
- 切换二维/三维展示同一来源的CAD SVG或实际模型，三维可拖动、缩放、键盘操作。
- 打开案例显示完整意图、对应二维/三维、完整中文YAML以及实际字节下载。
- 四个改版可保存新YAML、DXF、规格差异和几何补丁；原型只有其两份实际输入。
- “原型与改版对照”跳转到所选案例，查询参数由原对照页读取；未知参数回到默认案例。
- 仅两项受支持输入显示实际缝合外壳入口；三项保留BLOCKED，没有虚构新模型。
- 实验说明保留README全部资源链接、目录、验证边界及三个原有页面的返回导航。

## 必要偏离

概念图中拟真的服装与简化通用纸样不作为实际产物。实现显示当前DXF生成的五件静态
几何装配和真实四裁片布局；不修饰为已完成物理仿真的服装。缩略图保持原CAD布局，
不把四片重画成不符源文件的通用衣片。新增案例详情、完整规格和下载是用户已有任务
所需状态，沿用相同白底/绿线组件。小屏工具栏与单列卡片按同一设计系统延伸。

验收须比较原图与实际截图的布局、可见文案、字级、颜色、边线、图标、实际资产及响应式，
并实测筛选、空状态恢复、五个案例、18份下载、旋转/缩放、详情关闭焦点、说明和关联导航。
