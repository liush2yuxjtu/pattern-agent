# MakeHuman CC0 anatomical mesh

Current runtime asset: makehuman.json. Source: official MakeHuman hm08 base.obj, body group only, CC0.

Rendering and collision use the same processed, closed 4002-vertex / 8000-triangle mesh. This is a generic anatomical mesh, not a named-person scan.

See avatar-source.json and ../human-asset-report.md for hashes, source URLs, measurements, unit conversion, decimation and limits.
