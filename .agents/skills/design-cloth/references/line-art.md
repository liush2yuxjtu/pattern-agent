# 上身外观与服装线稿对照

## 确认对照对象

- 从用户提供的图片、文件或网页中找出实际服装线稿。保存的网页可能把线稿嵌成内联 SVG，单独列出图片或搜索 `img` 会漏掉它。检查正文中的 `svg`、`figure` 和相关样式，保留原始比例。可把内联 SVG 单独取出，补上原页面的笔画颜色，用本地渲染器生成 PNG。在 macOS 上可用 `qlmanage -t -s 1600 -o <目录> <svg 文件>`。打开输出确认线条完整。线稿作为视觉参考，纸样作为尺寸依据。
- 用户指「现在」或「这个」时，优先确认所选软件当前打开的工程。按[验证方法索引](verification/index.md)的上身外观手册采集同版证据。当前场景可能是试验副本，注明实际版本。若桥接不可用，可对照能确认来源的已有截图并注明版本和时间。避免为截图激活窗口或影响用户正在编辑的工程。

## 采集可比快照

- 先拿线稿有的对应视角，通常是正面。按需要补斜侧或背面，用来解释领口翻折、前襟叠合和下摆垂感。用一致的透视和裁切呈现可比较的视图，保留未裁切的原始快照。线稿没有标尺时，用肩、腰线、口袋、袖口等位置作为参照。
- 如果 3D 当前是透明、试穿图、应变图或应力图模式，同时记录当前显示，再用普通面料显示拍摄外观。操作前记录原显示模式，截完恢复。只切换视图所需的显示设置，保留模拟状态、缝线和面料。检查截图，确认覆盖层已消失、布料可见、目标没有被画面裁掉。需要比较扣合状态时，先说明两张图分别呈现怎样的扣合。

## 解释与交付

- 先给带来源和视角标签的并排图，再解释最明显的差异。分别看门襟扣合、领座与翻领、袖口和下摆。先说图上能直接看到什么，再检查工程中的纸样、缝合、闭合、面料和支撑证据。可以用这些证据区分视角、显示方式、穿着状态、布料模拟和工程结构的影响。
- 用工程、截图或原设计说明支持判断。例如，线稿画了双排扣而快照中前襟只在腰部靠拢时，先说明叠合和扣合状态的差异。仅凭扣子不清楚、布料不挺或出现褶皱，无法确认工程缺少扣件、衬布或用了错误纸样。纸样坐标一致只说明二维外轮廓一致。无法从现有证据拆分原因时，提出一个最小的单变量复测，并说明要观察的变化。
- 交付对照图和原始快照。用户要求修改时，在副本上改变目标变量，再用相同姿势和相机复拍。若任务重点是三姿势合体或四类试穿图，按[运行环境对照](runtime-support.md)选试穿路径。
