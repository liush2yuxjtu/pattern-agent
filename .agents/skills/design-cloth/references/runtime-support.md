# 运行环境对照

分别确认运行主机和调用接口。MCP 请求在服务配置的主机上执行。每个已试穿的尺码和姿势均应记录求解器、主机、工具和证据来源。

| 环境与接口 | 纸样、缝合与人台 | 新模拟 | 试穿证据 |
| --- | --- | --- | --- |
| **Style3D 桌面，经 MCP 调用原生 JSON API** | 按当前目录和权限读取人台、裁片、面料及缝合。 | 在所选软件可用且本轮授权时运行原生模拟并记录调度状态。 | 读取原生应力、应变、接触压力与几何快照，导出上身图。入口见 [Style3D 操作约定](verification/style3d.md) 与[逐项手册](verification/index.md)。 |
| **本机 CLO 3D，经 CLO MCP 调用** | 导入 DXF，在工作副本中装配、修改及缝合，并加载或测量人台。所需操作见[原生 CLO 试穿](#插件操作参考)、[批量缝合](#插件操作参考) 和 [人台量体](avatar-setup.md)。 | 实时桥接支持所需操作时，按确定的人台、面料和姿势做原生模拟，保存对应工程。 | 获取原生上身、合体、应力和人体接触压力图。有原生数值时保留测点或导出，另存网格以便复算应变与折角。 |
| **CLO_RUST，经 MCP 调用** | 审计已规范化的纸样与缝合记录或配对表。量测支持的人台网格，按需调整尺寸并独立复量。 | 复核或回放已保存的布料结果。新姿势需要另有已验证的求解路径。 | 从匹配网格复算应变、折角。核对归档的原生应力和压力图、点测数值，沿用同版原生图做外观或线稿对照。 |
| **本机 CLO_RUST 命令行** | 用兼容的 `pattern-native` 程序和已准备的输入检查纸样、缝合和网格。 | 适用于离线计算和已存结果复核。 | 按命令与输入记录输出。保存程序版本、匹配网格、图像和运行回执。 |
| **Boat 虚拟机的 Linux 环境，批量运行 CLO_RUST** | 用 [Boat 证据复核](#插件操作参考) 及支持的程序执行已准备的缝合、试穿复核与导出批次。 | 批量复核已存姿势。独立求解见下一行。 | 复算应变和折角，汇总传入的同版原生证据。完整 Boat 评审时，执行该技能要求的姿势与五类图检查，再交 [整衣验收](finish-verification.md) 判定约定的整衣范围。 |
| **Boat 虚拟机的 Linux 环境，独立 DXF 试穿** | 仅在服装、缝边与摆位映射、人台碰撞和姿势均符合已验证配置时使用 [Boat 独立试穿](#插件操作参考)。已验证的起点是直立与整体侧倾的合体长袖样衣。 | 用无界面的 Pattern Agent WASM 求解器做支持配置的新模拟。换款式、手臂动作或人台时，需先验证相应配置。 | 报告几何检查、应变、折角，以及注明来源的参考应力或接触结果。验收需要原生 CLO 图或经校准数值时，通过相应环境取证。 |

上表的 Boat Linux 路径使用 CLO_RUST 或独立 WASM 求解器。要用远程原生 CLO，先确认该主机上已获授权的 CLO 安装、实时桥接和所需接口均可用。

## 选择本轮路径

1. 按用户指定的环境执行。用 Style3D 时从 [Style3D 操作约定](verification/style3d.md)核实目录、权限及项目就绪情况。用原生 CLO 现场操作时先确认 `clo_status`，再读一次场景确认桥接可用。
2. 处理已保存的几何时，用现有 CLO_RUST 接口或兼容的命令行。用户指定 Boat、文件已在 Boat、或约定批处理依赖 Linux 时，可用 Boat。启动虚拟机或传输文件前核对授权、输入和运行版本。
3. 需要原生试穿加独立复核时，先采原生工程与证据，再传匹配的清单、缝合记录、网格、图和测点。核对工程版本、尺码、姿势、人台与量体、用料、闭合和单位。复算应变与折角前，核对网格坐标和裁片的纹理坐标。按实际回执记录执行主机。
4. 整衣验收缺少必需操作或证据时，按[工作流程第六节](workflows.md)继续取证。先查同版证据，再恢复当前取证能力或用已授权的可行环境完成受影响的视觉评审和测量。取得证据后交 [整衣验收](finish-verification.md) 复核。可行路径用尽时记录阻塞与恢复条件。

用 CLO_RUST 量体时，标明采用纵轴向上的哪一份人台网格，以及围度测量采用的闭合躯干截面。量测或改尺结果说明该文件的几何尺寸。实际试穿还需匹配的人台碰撞体和姿势。
