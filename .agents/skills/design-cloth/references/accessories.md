# CLO accessory review

Use the approved verification scope. Review the current design specification, actual pattern and sewing assignments, and revision-matched CLO evidence. When operating on a live project, avoid changing the user's working scene. Use a working copy for any functional exercise that changes project state.

1. List the applicable accessories by piece, side, and required behavior. Identify which positions, attachments, and functions the design requires.
2. Compare installed pieces and hardware against the specification. Inspect the intended host panel, placement and alignment, orientation, and sewing or attachment coverage. Use close-ups or project-side inspection for features that are not visible in the main fit views.
3. Verify any required opening, closing, or fastening function through evidence of the actual action in the environment being assessed. Record whether a buttonhole is a marker, an opening, or part of a demonstrated closure. Label untested functions and physical behavior as pending within their requested scope.
4. For a Carlton Pattern Agent browser-workbench case, use the [Carlton workbench procedure](carlton-workbench.md) to collect matching evidence within scope. Reuse its measured and visual findings for the matching case. When the gate asks for native CLO behavior, use evidence from that native project.
5. Return accessory, requirement, result, and evidence rows for [整衣验收](finish-verification.md). Include the project revision, environment, pose or closure state, and any missing evidence. For a failure give the location, observed defect, proposed change, and repeatable retest criterion. For in-scope repairs in an end-to-end task, follow the [main workflow](workflows.md).
