# 应变 · CLO 3D MCP

有原生 Strain Map 时采集视图与色标。按 [CLO 操作约定](../clo3d.md) 核对当前接口能否读取原生值。可用 `scene_export` 获取同版 GLB，先确认原始位置与纸样 UV 均为毫米，且裁片与 primitive 对应，经核验的网格可交 `mcp__clo_rust__strain` 计算主工程应变和面积加权 P95%。若根节点存在变换，区分文件访问器与世界坐标单位。保留原生显示与几何计算的各自定义。

袖口、肩背或臀部的峰值应在姿势一致时对照面料允许伸长、松量和相关缝合。未知 UV 比例时保留原生图，几何数值待验证。
