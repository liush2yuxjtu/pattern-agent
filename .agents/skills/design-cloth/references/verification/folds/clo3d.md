# 褶皱与折角 · CLO 3D MCP

用 `snapshot` 保存同姿势的褶皱部位。按 [试穿图导出](../../runtime-support.md#插件操作参考) 或 `mcp__clo_rust__fold_angles` 用核对过单位和裁片映射的同版服装网格，计算裁片内相邻三角面无符号折角，0° 为平面。每次复测从同一份保存的网格生成折角图和对应统计，记录网格标识、取样部位、P95 或约定统计、有效边数和阈值。修前与修后可使用各自的网格，比较时沿用同一部位、定义和可比的网格分辨率。

按设计区分计划褶与牵拉褶。网格分辨率不同或缝线层次变化时，先核对可比性。边数用于说明网格测量覆盖，实体褶的范围从整体与局部图判断。

外层遮住里布时，在同一保存状态单独显示疑似裁片。保留相对人台的侧视位置及前后方向，再配折角图判断它卷到了哪里、哪里折得急。人体压力及修复效果通过同条件的原生压力图和测点确认。
