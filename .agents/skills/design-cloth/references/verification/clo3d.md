# CLO 3D MCP 操作约定

- **确认桥接。** 实时操作先查 `clo_status`，再用 `scene_info` 确认目标工程及现场。已归档证据可直接从同版文件开始。
- **核对版本能力。** 本目录中的直接工具来自 `mcp__clo3d`。需要下探原生 API 时用 `clo_api_search` 或 `clo_api_catalog` 查当前运行版本，再用 `clo_api_describe` 验证签名；按任务权限用 `clo_api_call`。只查文档时到描述为止。避免在唯一工程上试探未经验证的原生签名。
- **UI 补证。** 用 `clo_control_guide` 确认可用路线。能用现成原图、同版工程证据或已确认接口时优先复用。获授权使用 UI 时，核实实际显示模式、图例、工具与结果。尊重用户桌面焦点要求。
- **区分证据来源。** `mcp__clo_rust` 适用于已存 CLO 证据和支持的离线计算。原生应力和压力需要同姿势原生读数或导出。原图与测点要匹配项目、尺码、姿势、模拟状态、实际面料、闭合和单位。

按 [验证方法索引](index.md) 进入对应手册。插件中的采集和导出细节见 [运行环境对照](../runtime-support.md#插件操作参考)。
