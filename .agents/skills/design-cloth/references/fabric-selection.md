# 根据已有纸样挑选布料

先判断纸样需要布料怎样伸展、垂落和定型，再给具体布种和可验证的采购条件。跟随用户指定的用途、廓形、材料和输出语言。只做选布时，有纸样和说明即可开展。

## 从纸样提取要求

1. **核对原版说明。** 优先读对应版本、尺码和款式的推荐布料、最小伸长率及方向、成衣尺寸、布幅、排料和辅料说明。已有实物样衣时，可用原面料或样衣作比较基准。说明中的明确要求、从纸样推断的条件和需要实测的信息都应有出处。
2. **看版型、穿脱和丝缕。** 仅有裁片时，先核对比例、裁片数量、对折与镜像、净缝线和缝份。沿同一身体水平线量成衣净围度，按缝合关系计入前后片、闭合省道、褶裥和门襟净搭量。用成衣净围减对应人体围度，记录净松量。分别看穿着和穿脱所需空间，比如闭合领圈过头、无开口腰头过臀、紧袖口过手，以及抬臂、坐下时受限的部位。结合拉链、纽扣及穿脱路径判断是否依赖面料伸展，按丝缕标记找出需要伸展的实际方向。人体尺寸、比例或丝缕无法核实时，列出条件式候选。
3. **把纸样特征转成面料条件。** 分清穿脱和动作所需的条件，以及轮廓、手感和制作上的偏好。贴体套头款优先看实际方向的可用伸长、回弹和成缝弹性。斜裁或大摆优先看对应方向的垂感、下垂伸长和下摆稳定性。领座、驳头、明褶和硬挺下摆优先看支撑、熨烫定型和叠层厚度。同一纤维或克重可以有不同组织和手感，如果缺少原版依据和布样，只给保守的候选范围。
4. **把辅料一起核对。** 罗纹领口、腰头、松紧带、里料、贴边和衬按各自用途选。检查领边试缝后的开口和回弹，里料和衬是否限制外层所需的活动，翻领、袖口和门襟叠层是否过厚。给用量时以实际可用布幅和排料为准，把预缩、对条对格、单向倒顺毛和斜裁考虑进去。

必要时用 `max(0, 通过所需尺寸 / 开口净尺寸 - 1)` 粗估某个闭合口的几何延伸需求。仅在量测路径可比且确实依赖开口伸长时使用，说明形状、局部受力和缝线都会改变实穿结果。纸样净松量和这个估算均无法单独给出采购用的最低伸长率。

## 比较候选和验证

- 结合用户目标给首选与有意义的替代项。对每项说明推荐的组织和手感、纸样依据、可直接替换的条件，以及值得先试缝的部位。候选布有明显缺项时给条件式结论。改版、改变丝缕或增加开口作为独立方案提出。
- 布样测试和资料查阅见 [布样与 CLO 验证](fabric-selection/verification.md)。优先按原版伸长尺或供应商已说明的方法复核。布样筛选后，用计划采用的针线、缝法和辅料试缝关键部位。样衣用物性接近候选布的材料，特别是贴体针织和斜裁款。
- 需要数字对照时，用同版、同姿势和相同模拟条件比较不同布料，确认物性来源和丝缕。只拿到 CLO 预设时，将结论限定为对趋势的初筛。需要完整多姿势试穿时衔接 [原生 CLO 试穿](runtime-support.md#插件操作参考)。
- 交付用中文先给选布结论，再说明纸样依据和要复核的项目。有布样或截图时，优先用可见证据说明差异。注明原版规格、供应商标称、布样实测和 CLO 预设的来源。
