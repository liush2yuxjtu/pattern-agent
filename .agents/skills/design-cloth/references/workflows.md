# 服装设计与试穿工作流程

## 一、确认需求和当前进度

确认款式与设计参考、目标人体尺寸、材料约束、必测姿势和验收条件。清点现有起版输入、DXF、CLO 工程和证据，从第一项未完成的步骤继续，复用同版本仍适用的证据。单项任务完成对应步骤即可。

只有设计意图且需要母版时，从 [FreeSewing 款式目录](https://freesewing.eu/designs/)查找合适的款式、原型或裁片，核对结构和面料条件。只做参考选型时，交付首选母版及相关备选。

## 二、确定面料和人台

- 沿用用户或设计指定的材料。面料未定、需要替代或适用性不明时，参照 [选布](fabric-selection.md)，传入设计意图、参考、纸样及布样或供应商资料。弹性、垂感或支撑性会影响起版时，先确定临时方案，纸样核对后再复核。
- **人台尺寸影响起版时先核对。** 当起版使用人台数据，或现有尺码匹配存在疑点时，按[人台量体](avatar-setup.md)确认实际加载的人台与尺码设定。逐项记录目标值、实测值、差值、单位及测量部位或方法。目标值采用起版输入或对应 DXF 的人体尺码表。松量另用成衣纸样尺寸计算。按款式要求和已约定限值评估差值，有影响的偏差先在副本中换人台或调整，再重测相关尺寸。修改一项身体尺寸后，复查受影响的其他尺寸。
- 若先定人台且暂无目标尺寸，测量该人台后可用实测值起版并在试穿中复用。若已有目标穿着者但其尺寸缺失，记录代用人台和假设，按探索性试穿处理。正式人体尺寸匹配待补证。

## 三、准备纸样与各尺码

| 输入或目标 | 处理方式 |
| --- | --- |
| 修改样版 DXF | 用已授权的原生 CLO 纸样编辑功能或现有工程编辑器，在副本上修改。按需核对导出或回导的单位、裁片、净缝线、缝份、刀口、丝缕与配对边。 |
| 修改现有 FreeSewing 参数纸样 | 参照 [FreeSewing 起版](freesewing.md)，记录母版版本、修改前后的参数或量体数据，重新出样并核对。 |
| 从零建立 FreeSewing 参数纸样 | 按 [FreeSewing 起版](freesewing.md) 使用需求、参考或母版，保留可运行源码、准确的输入和参数化检查记录。 |
| 接收或生成一组尺码 | 对照已记录的尺码和人体尺寸识别每份来样。生成时采用各尺码实测数据或约定的放码规则。每个尺码保留独立 DXF 和版本记录，写明实际完成纸样检查和人台试穿的尺码。 |

已有 DXF 或 CLO 工程时，按当前问题选择检查或直接评审已有结果，复用与当前输入匹配的证据。修改时从原版建立候选副本。

## 四、装配、模拟或复核已有结果

按[运行环境对照](runtime-support.md)选择适合本轮的执行环境。新原生模拟和原生图依赖所选软件的可用接口。按[验证方法索引](verification/index.md)查 Style3D 或 CLO 3D 的操作手册。CLO_RUST 与 Boat 可独立复核兼容的已存证据。Boat 独立求解限于已验证的 DXF 配置。

### 四类常见问题

按症状、最近改动和同版证据自主选查。先用成本低且能区分原因的检查。需要时可在初次试穿前检查，也可看到异常后再回查。能直接用现有记录判定时复用记录。每次快查记录对应版次、发现和证据。

| 常见问题 | 何时选查及怎么查 |
| --- | --- |
| 人台与纸样不符 | 整体松紧异常、有换尺码或重新导入时，比较实际人台和起版人体尺寸或 DXF 尺码表。按需记录目标、实测与差值，另用成衣纸样计算松量。用一条已知长度核实 DXF 单位和比例，再查版次、净缝线、缝份、刀口或镜像等相关细节。 |
| 面料赋值或物性偏差 | 垂感、伸展或层间表现异常时，核对受影响的面布、里布、衬料、丝缕和所用物性。区分实测、供应商数据、预设与代用，必要时做只换面料的对照。 |
| 缝合或扣件异常 | 局部牵扯、错扭、开口或缝线分离时，检查配对边、方向、起止点、覆盖、工艺放量和实际闭合。按需用[验证方法索引](verification/index.md)的缝合或扣件手册验证。 |
| 姿势、摆位或碰撞 | 换姿势后才出现夹布、穿模或翻转时，核对实际人台、姿势、裁片摆位、左右层次和碰撞。区分初始设置与求解后的稳定性。 |

已知偏差会影响本次判断时，先修正或用受控对比隔离影响。模型可从已存证据、快速检查或诊断模拟着手，根据结果切换路线。疑点仍在时明确证据缺口，按[定稿与疑难交接](#定稿与疑难交接)继续。

### 模拟与取证

按[运行环境对照](runtime-support.md)选择试穿路径。参照[验证方法索引](verification/index.md)的模拟稳定性手册做所选软件的原生模拟，或从匹配的已存模拟取证。确认成衣在目标姿势和闭合状态下稳定，检查穿模、缝线分离、翻转或异常牵拉。保存各必测尺码和姿势的工程与证据。

### 五种验证方法

根据当前问题选择最能支持判断的图和数据。可先用一项排除疑点，再补齐其余适用证据。使用任一方法的结果都应对应候选版、尺码、姿势和适用范围。

| 证据类别 | 取证方法 |
| --- | --- |
| 上身外观 | 采集正背面和必要侧视。对照设计时，同排放置视角与闭合状态可比的上身图和线稿，按需参照 [线稿对照](line-art.md)。标出轮廓、衣长、领口或配饰差异。有可靠比例时可报距离。 |
| 应变 | 用原生图或匹配网格的经验证计算结果。保留百分比色标、应变定义、方向和受影响区域。 |
| 应力 | 保存所选软件的原生应力证据、单位及色标。有对应的原生测点或数值导出时，记录位置与读数。 |
| 试穿压力 | 保存原生人体接触压力图、单位及色标。有原生读数时，标出施压部位和采样覆盖，注明统计按接触样本还是整个区域计算。 |
| 褶皱与折角 | 用折角图或标注褶皱的视图定位。保留同一网格的角度数据、单位、定义与测量部位。 |

优先复用有效证据。按[验证方法索引](verification/index.md)选择所用软件的取证手册。可用 CLO_RUST 复核兼容的 CLO 证据。每组证据随附尺码、姿势、工程版本、人台、实际面料和闭合状态。应力和压力的数值以对应原生测点或导出为准。

## 五、诊断、修复与同条件复测

自行在[常见问题快查](#四类常见问题)与[验证方法](#五种验证方法)之间切换。证据已指向具体原因时直接处理。原因仍含混时选一项能区分候选原因的检查或单变量对照。Carlton 网页工作台可按[Carlton 工作台](carlton-workbench.md)另采对应配饰证据，注明其运行环境。

自动执行范围内、有证据支持的修复。保留基准版和各次测试版，记下问题、改动量与实际效果。除待验证的变量外，保持尺码、人台、面料、姿势、求解设置、闭合状态和视角可比。每次修改后重查受影响的输入或证据，再复测受影响的尺码、姿势和部件。面料或人台变化影响松量或结构时，重查起版与缝合。有退步时保留验证表现较好的版本，继续尝试有证据支持的下一条修复路径。涉及设计意图、尺码与姿势、验收条件或固定输入的变更，由用户决定。

## 六、判定与交付报告

### 数字验收的三条路径

对同一候选执行[整衣验收](finish-verification.md)，按必验尺码与姿势汇总检查结果。模型自行选择快查、试穿与取证顺序。保留各项目的证据链接和状态。确实超出约定范围或不适用于款式的项目，标明不适用并说明理由。

| 验收结果 | 下一步 |
| --- | --- |
| 有已确认的缺陷 | 在工作副本修复范围内的问题。按改动影响选择复测，复用仍有效的证据，然后回到同一验收关口。可并行补采与修复互不影响的证据。 |
| 证据不足，暂无法判定 | 先复用可信的同版图、读数与网格，再选能填补缺口的取证、复算或受控对比。图与读数须对应同一候选版、尺码、姿势和模拟状态。补证后回到同一验收关口。需要用户输入或决定时，按下一节交接。 |
| 全部适用项通过 | 打样交付同一验收版本的定稿纸样、3D 渲染及定稿报告。纸样与渲染默认用 DXF 和 PNG，用户指定格式优先。报告记录款式、版次、尺码、验收结论、关键证据和修复复验结果。默认报告格式见[报告要求](#按问题安排正文)。 |

### 四姿势五类验收

正式试穿报告按每个交付尺码安排四个不同姿势。优先使用本轮已约定的姿势，按服装用途确定具体动作并记录。单项检查和探索试穿可交候选记录。

1. 对每个姿势的同一候选版执行[五种验证方法](#五种验证方法)。逐项记录状态、判断依据、原始图及对应读数或设计对照。先核对图片、读数、姿势和版次相符，再按本款的条件判定。压力画面有标记而人体侧读数全零时，先核实原生人体侧测量，继续保留该项为待确认。
2. 发现缺陷时修正并复测受影响的姿势和项目。证据不足时补采、复算或做受控对比，直到有通过依据。必须等用户输入或软件能力时，记录具体缺口和复测条件，交候选记录。
3. 四个姿势的五类检查都通过后，把对应的实测证据图填入[发布图片清单](试穿报告模板.md#markdown-发布)。固定导出脚本检查四个姿势与二十个证据项是否各有可解码的图片。文件检查通过后才生成定稿 Markdown。图片的来源、读数和验收结论依前两步核查。

### 定稿与疑难交接

范围内的取证和修复可继续时，沿上述路径推进。可行路径用尽，或必须由用户提供输入或决定时，交付候选版及可核查证据。标明当前验收结果、已证实的缺陷、未解问题、涉及的部位和姿势、已做尝试及其结果。给出首选下一步、需用户提供或决定的事项，以及复测通过条件。用整体定位图或局部图支撑相应判断。

需要用户补证或选择下一步时，优先调用 `AskUserQuestion`。当前环境若以其他名称提供结构化提问工具，例如 `request_user_input_async`，使用可用工具。提问指向报告中仍会改变下一步的具体决定或缺失数据，附证据出处和推荐动作的理由。有实际可选方案时，列出可执行选项及各自影响。只需文件、读数或说明时，用一个简短的问题索取该项资料。每次仅询问当前所缺的信息。可独立完成的工作继续推进，依赖答复的分支保留待确认。工具不可用时，在对话中提出同一个具体问题。

收到用户的证据、决定或修订版后，接续同一条验收记录。核对新旧版次，自主选择受影响项重查，其余证据在仍适用时复用。修复或补证后回到数字验收，全部适用项通过才定稿。

定稿后的实物验收以样衣和真人试穿的证据为准。实物问题涉及版型或用料时，按影响范围返回数字流程。缝制工艺偏差可直接返修样衣并重新实物验收。

### 按问题安排正文

使用[试穿报告模板](试穿报告模板.md)，沿用 M 码女式紧身针织 T 恤四姿势范本的阅读顺序。正文按问题组织，五类证据用于核对验收覆盖。

- 开头用醒目的大标题和项目符号交代优先问题、关键数字、范围及结论，再用大图比较各必测姿势的整体上身。每个重点部位放局部大图、简短读图说明与对应表号。跨姿势和修前修后比较用可比的尺码、部位、视角、闭合状态和色标。
- 正文用多级标题、大图和少量文字说明试穿条件、发现与复测记录。用图号与表号关联图像、取样范围和统计。把补充图片直接放在相应章节，工程、网格及原始测量记录可作为配套文件提供。五类证据可按问题组合，选配图随本轮问题取舍。
- 末尾用项目符号把第一优先行动讲完整，依次列其他必要动作。每项写明部位、依据、负责工具、要单独改变或补采的内容、复测姿势和通过条件。需要用户决定的设计取舍在这里列出。

正式试穿报告默认交付 Markdown（.md）、图片子目录及发布清单。每个姿势、视角和证据逐张放独立图，用相对路径引用并注明图号。按[Markdown 发布](试穿报告模板.md#markdown-发布)通过图片检查，在宽屏和窄屏预览图片、标题、表格与结论顺序。明确要求离线 HTML 时用同一清单导出 .html。单项检查可在对话中简报，局部试穿判断也须直接呈现对应图片。
