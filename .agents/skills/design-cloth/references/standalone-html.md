# 独立 HTML 六项发布关口

独立 HTML 应当是版师可以单独保存、打开和复核的报告。先把设计和验收范围固定到款式、版次、尺码、人台、面料、闭合状态及每尺码四个姿势。读 [整衣验收](finish-verification.md) 取证，再按以下六项逐条检查最终文件。

1. **仅交付读者需要的文件。** 报告正文、图像、样式和关键数字均在同一 HTML 内。默认仅交这一文件。生成脚本、日志、清单和临时产物留在工作区。额外纸样、工程和原始证据包按用户指定的交付范围处理。无网时无需复制同目录资源或启动服务。
2. **先给读者结论。** 默认展开「先看结果」，写清款式、版次、尺码及覆盖范围，以及最重要的部位、现象和结论。用人能复查的关键数字或图指引支撑结论。正文使用日常语言。
3. **给出可执行的下一步。** 在正文最后一节默认展开「分诊与下一步复测」，沿用已有编号，按优先级写清谁做、在哪个姿势看哪个部位、怎样算通过，链接到对应的图或读数。数字验收已结束时，写明结案范围和本轮无需复测。
4. **直接显示关键证据。** 默认展开「关键证据」。挑选与 TL;DR 及首项后续直接相关的独立大图。每图有可读图注，标明姿势、部位、来源与适用限制。用锚点连接结论、图、复测任务。不能把布面压力、接触力或代理读数当成人体侧压力。
5. **完整证据按需展开。** 用默认收起的原生 `<details>` 和有意义的 `<summary>` 组织逐姿势验收、全图、单位、测点或分片读数、阈值、对照依据与来源。为每个五类格保留对应的实际可查图证；浏览器无需脚本即可打开。核查完整证据里的图在展开后实际显示。
6. **五类验收全部通过。** 按每尺码四个不同姿势分别验证上身与线稿、应变、应力、人体接触压力、褶皱折角。同格中的图与取样或判读依据要对应同版、同尺码、同姿势和可追溯的模拟状态。原生应力与人体压力须有有效、可定位的数值及单位。补采压力引起重新求解时，核对新的求解状态，按同一状态重新采关联证据。使用题设或已确认的验收标准。缺证、失败、阈值缺失、无效或冲突采样均不得签发。优先补证与修复，确有阻塞时在聊天交代范围、证据和具体复测条件。人体侧压力阻塞签发时，第一项复测应同时要求同版、同姿势的原生人体压力图（保留色标和单位）及可定位的有效读数，再按实际覆盖和采样一致性判定。图像齐备和技能评测通过各自有独立含义。

## 发布回读

报告使用可访问的 HTML 和内嵌 PNG、JPEG 或 WebP，样式写在文件内，折叠使用浏览器原生组件。给默认打开的摘要、关键图和分诊末节分别设置 `id="focus"`、`id="evidence"`、`id="follow-up"`。在分诊末节之前用 `id="audit"` 组织折叠证据。每个验收格的锚点放在对应的 `figure` 或包住证据图及记录的容器上。

用 `scripts/check-standalone-html.py REPORT.html REVIEW.json` 检查页面结构、内嵌图片和独立复核记录。REVIEW 留在工作区。它含 `revision` 和非空 `sizes` 对象。每个尺码映射四个姿势，每姿势有 `appearance`、`strain`、`stress`、`pressure`、`folds`，各项写入实际判定 `status`、证据图 `anchor`、评审 `basis` 和原始证据 `source`。只有逐项确认过的通过可写 `pass`。每格有唯一锚点。程序检查结构和声明，本身不能判定压力真伪或服装合身。

最后把 HTML 单独复制到空目录。在可用的目标阅读器中离线打开，确认默认关键图解码且可见、章节链接有效、折叠默认收起且可点击展开和收起、展开后所有图可解码、缺少外部资源仍可阅读。检查首屏和重点图注，并记录实际测试的阅读器。在对话首条链接交付最终报告，随后说明服装通过范围与重要后续。
