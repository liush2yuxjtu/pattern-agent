# 跨商品拟合流程

用于新电商商品、不同裁切和不同手势。复用厘米校准、FK/LBS 和渲染基础设施，重建本次观测，
避免把上一件商品的成功或失败参数当作新输入的身体。

## 1. 建立本次观测

实际查看原图并记录原生宽高、人物裁切和遮挡。每个标志点写清它是可见人体点、衣服表面点，
还是推测的内部关节。领口/肩缝/腰带不能直接替代颈/肩/髋骨头；宽松衣物边界不是裸体表面。
插袋或挡住的腕、掌不补成“可见测量”，保留 null 与假设。Image Gen 点线有帮助，但仍需
配准与语义核对，不能覆盖原始照片中相反的可见证据。

若为效率缩小输入，保存原图到工作图的精确变换，最终矩阵和叠加映射回原始像素。不要套用
此前固定分辨率的中心点、ROI、相机尺度或手腕坐标。表面代理保存真实顶点索引及其定义。

## 2. 从中性人体重建相机与姿态

采用授权的尺寸先验和中性完整骨架初始化；身高只确定假设尺度。先从人物/躯干框初始化
取景，用脸、肩部构架、躯干与骨盆中心共同约束，避免只追眼鼻和手腕。
可见身体近似长焦时说明正交近似，明显透视时使用相应相机。至少比较正面与合理斜视的相机
初值，保留各自真实渲染，检查是否把局部关节错误转移成极端相机。相机碰边界须查原因。

先使整体构架落在正确位置，再分别拟合上肢。上臂、肘、前臂和腕共同决定深度，不能为
对齐腕点把肘拖到腕下或反转前臂。骨长/表面尺参数可以在明确的合理范围联合调整，但
宽松服装下的胸腰臀保留先验属性；缩小身体躲进衣服不构成人体恢复。

按本图动作选择手部约束：自然下垂、插袋、交叠、提衣不是同一模板。只有原图支持时才
加入两手接近/捏合的弱先验，不把提衣代码套在自然下垂图上。先稳定肘腕，再冻结躯干和相机
局部调整腕部旋转与指骨。看真实侧背，不把二维点接近当作掌背朝向或三维接触成功。

裁切外的腿脚和隐藏深度保留为可解释先验；不可为了上半身投影倾斜整个人体或破坏站姿。
自然垂手在躯干轮廓之外时，手腹射线零覆盖应记 N/A/UNKNOWN，不可伪称碰撞通过。

## 3. 保存实际结果，再用结果决定下一步

从最终完整状态导出实际网格、关节与相机，重新渲染原相机及正侧背。同一版本必须能在
可调编辑器读回。中性网格测量、实际骨头段长、姿态角度与可观测尺寸分别报告。
检查最差区域、可见腕与粗方向；用带覆盖范围的几何检查和三维目视判断动作。

若新轮次解决穿腹却反转前臂、靠旋转相机破坏腰臀，保留为失败而不自动晋升“最新最佳”。
每个参数块记录进退和预算；缺少可靠观测的尺寸不强行拟合。达到平台期交付最佳可解释
候选和剩余失败，供官方 eval.html 人工评阅，不能用模型可编辑代替原图动作已匹配。

## 从执行轨迹改进求解，而非只改评分

拟合前在原图保存可见腕部的局部标注核查图：手腕不是挽起袖口。引导图点落错位置时，以
实际可见皮肤/手掌连接为准；隐藏腕只能用带来源的粗区域先验，不能补成测量点。保留标注
不确定性，并分别检查可见腕残差，别让整体轮廓变好掩盖手部位置退步。

优化参数用 `(bone_name, axis)` 显式映射并打印约束对象；不要用 `xx[18:21]` 猜它属于脊柱。
二维相机/关节点损失可能通过累积脊柱反弓、颈部反向补偿或将上臂扫到身后来降低。
对明确的站立自然垂臂，先比较不弯脊柱的解，再按可见证据开放必要自由度；检查整条骨盆到
颈部的世界构架和实际肘弯，而非只限制单个关节角。约束深度使用人体朝向/躯干相对坐标，
不要把所有肘腕夹到同一个世界 Z 平面。插前袋和背手不同；即使精确腕掌被挡住，也要核查
可见前臂与前袋侧区域是否支持把手放到臀后。

对实际保存的 FK 关节运行捆绑的诊断工具，按原图动作选择 profile：

```sh
python scripts/audit_pose_geometry.py --joints model/views/joints.json --state model/final-state.json --profile standing-relaxed --out evidence/pose-audit.json
python scripts/audit_pose_geometry.py --joints model/views/joints.json --state model/final-state.json --profile front-pocket --pocket-side L --out evidence/pocket-audit.json
```

L/R 指人体自身左右，不是图像左右；无足够动作证据时使用默认 unconstrained。工具读实际
Y-up/cm 关节，以髋部定义朝向，报告累积构架、肘弯、向后扫臂及后方腕等启发式。它不做
原图检测、碰撞仿真或自动 PASS；阈值是公开的诊断先验，不是评估器真值或必须逼近的目标。
有警告时查看真实侧背并修正或明确保留失败，不要通过改字段/标签消除警告。

生成最终图前先完成侧背检查，并按编辑器范围/0.1 步长规范化同一状态，再重建全部几何。
保存每次生成真正输入的 state、相机、render 字节和 SHA。若之后再改人体，另存新版本并
明确哪些图片仍基于旧输入；不要用最终文件名覆盖生成前证据，也不把后来的动作修复当作
旧生成图已经保持了新姿态。生成六张不等于几何一致；逐角色检查可见的手臂/躯干姿态是否
被生成器自动“摆正”，并将这类未覆盖的质量问题写入 claims/eval_feedback，而不是错扣
商品领口/袖长等不相干断言。
