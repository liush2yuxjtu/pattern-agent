# FreeSewing checks

For a script, construct a fresh design per sampling run. In core 4.10.2, use `new YourDesign({ ...settings, sample: { type: 'option', option: key } }).sample()`. Use `{ type: 'measurement', measurement: key }` or `{ type: 'models', models: { label: measurements, ... } }` for the other modes. Some documentation examples omit `type`. Validate the actual sample count and applied inputs from the returned pattern, and render the sampled overlay. Verify the installed API first for other versions. Inspect the settings generated by the measurement sampler and draft an explicit endpoint if it omits one. Scripted drafts of explicit inputs also work when a sampling UI or method is unavailable.

Use fresh settings for a nominal case, individual option sweeps, realistic complete measurement sets, and selected combinations. Check that the design renders every expected piece. For each matching pair, measure along the actual intended sewing paths and compare with the construction spec, including deliberate ease or gathers. Derive assertions from the intended fit and functionality. When a draft loop searches for a geometric target, check the residual and bound the iterations so extreme inputs fail visibly.

## Tutorial bib smoke test

Use the [tutorial's rounded bib outline](https://freesewing.dev/tutorials/pattern-design/part2/rounding-the-corners/), or the corresponding Tutorial template. Its required measurement is `head`. Start at 380 mm. The default neck/width/length ratios are 0.80/0.45/0.75, with ranges 0.70–0.90, 0.35–0.55, and 0.55–0.85.

- Compare the original quarter-neck curve to `head × neckRatio / 4` within the tutorial's 1 mm tolerance. Separately check the final neck and closure after the straps are rotated.
- Check that width increases with widthRatio, usable length increases with lengthRatio, and the mirrored strap tips clear each other in the flat draft. Measure usable coverage from the bottom of the neck opening to the hem as well as total height. The tutorial's original width computation shortens that coverage as width increases. Report it explicitly when verifying the original and add a coverage-invariance check if a redesign is requested.
- Compare nominal and 1:10 normalized geometry. The original bib uses absolute millimetres for neck tolerance and strap clearance. Their effect is visible in the reduced case.
- The bib is a single panel. Verify its closure independently from ordinary seams. Obtain the snap anchors from the [annotation chapter](https://freesewing.dev/tutorials/pattern-design/part3/annotations/) or the matching Tutorial template. The paper pattern's snap marks indicate placement and still require a physical closure in CLO.
