# 配饰、扣件与闭合 · Style3D MCP / API

用 `Button.GetAllIds`、`ButtonHole.GetAllIds` 和 `Zipper.GetAllIds` 枚举实例，用 `Accessory.GetAccessoryProperties` 读取适用的位置、旋转等实例字段。核对修饰件附着时可查 `Trim.GetAttachedEntity`。用 `Snapshot.ExportImage3D` 保存成衣整体和问题细节，并结合 [缝合检查](../sewing/style3d.md) 核对实际附着。共享款式尺寸需要另有证据。

锁定和穿带等功能判断需要约定开合状态的直接证据。仅做检查时沿用当前设置及已有记录。
