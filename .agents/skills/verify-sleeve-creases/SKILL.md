# 袖子尖折取证与诊断

工作目录为 Pattern Agent 根目录。先读 [AGENTS.md](../../../AGENTS.md) 和
[项目 verify](../verify/SKILL.md)。按 [可执行配方](../verify/references/sleeve-creases.md)
做本地 `/verify`，随后直接向 main 提交、非强制推送；不使用 CI、PR 或 Issue。
Claude 通过 `.claude/skills/verify-sleeve-creases` 发现同一份源文件。
文件存在不等于已测得原生客户端自动触发率。

## 先确认要证明的事

“整体箱形轮廓”可能是落肩等设计意图；“局部尖折”是需要测量、定位的几何候选。
先记录期望款式、实际文件 SHA-256、版本、姿势、裁片 ID、三维米／纸样毫米单位、
网格分辨率与排除区。保留原始坏模型；不能用重新生成的模型替换它后沿用旧截图。

按 [方法与边界](references/method.md)区分四类证据：截图、真实表面几何、
真实求解过程、实物面料与个人合体。检测到折角不能独自证明纸样错误或唯一物理原因。
需要证明某项求解约束的作用时，保持纸样、网格、初始状态与迭代数相同做消融对照。

## 独立重读网格

直接执行随技能提供的 Python 标准库 CLI，不调用页面的检测函数：

```sh
python .agents/skills/verify-sleeve-creases/scripts/inspect.py \
  --input actual-export.json --out work/sleeve-creases/report.json \
  --trace work/sleeve-creases/performance.json
```

输入是 `garment-body-wear-audit-input/2`，也接受工作室导出文件的 `geometry` 字段。
每个袖片必须有 `partId`、米单位 `vertices`、`triangles`、毫米 `points2d`、带
`underarm-*` 标签的 `boundary`。没有单位或语义时报告 INVALID，不自行猜测。

1. 从三角面的实际位置计算有向法向，按真正共用的顶点索引建立邻接。
   使用 `atan2(|n1×n2|, n1·n2)` 得到 0–180°，不能取 `abs(dot)` 把折回的
   170°误判成10°，也不能使用渲染器的平滑顶点法线。
2. 单独报告退化面、非流形边、相邻面绕序不一致。不能把翻面当成正常折痕，
   也不能把没有有效测点判为 PASS。
3. 按原纸样 UV 中的边中点到袖底缝的距离，明确保留15 mm排除区的边、角度、数量。
   排除仅作用于该折角统计，不免除该区域的碰撞、接缝或自交检查。
4. 本次无结构装袖样例的硬折角目标为≤45°；25–45°用橙色提示，≤25°蓝绿，
   >45°洋红，排除区灰色。阈值和采样随网格记录，不能作为所有服装的行业标准。
5. CLI 的 PASS 仅表示此硬折角诊断通过。完整平顺性仍按项目原检查器核对内部
   P95≤25°、上袖山 P95≤30°、向内反折≤45°、镜像误差≤0.5 mm；接缝、人体碰撞、
   自交、材料和实物合体均保持各自结论，不被这个 PASS 覆盖。

CLI 退出码：0=本项PASS，2=发现超限折角，3=输入无效或无法测量。
启动／依赖失败另记 BLOCKED；不要把所有非零退出都解释成衣服缺陷。

## 高亮具体位置，再配对修复前后

用相同镜头显示原网格与修复网格；颜色由测量值驱动。点击条目显示裁片、边／面编号、
材料坐标、角度、是否排除，画出两个实际面方向；光照变化不得改变测量结果。
相连的超限边可作为折痕候选，但还须结合款式意图与网格密度。

顶点编号在重网格后可能变化。仅在原型、材料坐标系和来源已确认一致时，比较同一
裁片的两个 UV 端点（允许端点顺序交换）。冻结样例容差≤0.01 mm；无匹配时明确
写“无法同边比较”。不能以最近三维点或相同顶点编号冒充同一材料位置。
陌生导入工程不自动认作历史样例的修复版本。

## 记录真实计算，不把性能当形状判据

- 用 User Timing 标记读取、几何检测、渲染、选边等阶段，输出实测耗时及关联文件摘要。
  Chrome Trace 使用微秒时间戳；帧耗时不能替代折角、碰撞或材料检查。
- 声称“捕获求解中的异常”时，实际绕开预计算缓存执行求解，记录代数／迭代、
  最大折角、超限数、对应节点及最终导出网格。进度回调必须属于当前运行，取消旧任务
  后不能把旧结果计入。启用观察不得修改位置或放宽约束。
- 旧网格的检测日志标为 archived-mesh-inspection；没有旧求解器逐帧数据时，
  不把当前重测时间冒充旧模拟发生时间。工具测量不是校准的弯曲应力或压力。

## 验证与交付

先运行 [本地正反例](../verify/references/sleeve-creases.md)，确认已知坏模型被拒绝、
正常圆柱不误报、170°折回不漏报、翻面和退化输入不获通过。随后操作实际 UI：
着色开关、同边选择、旋转、导入／导出、手机窄屏、真实求解与日志下载。
页面的断言需和独立 CLI 逐边比较，不能只看截图或自报 PASS。

在新的 `docs/verification/` 目录保存候选源码摘要、命令／退出码、输入摘要、
正反例、真实浏览器证据、线上读回与每项结论。解释时用具体位置和前后角度，
区分“这条可见尖棱”和“全袖最大值”。
历史 T 恤7.6455 mm间隙／20处自交 FAIL继续保留；本技能不将物理合体升级为通过。
