# 接缝与三维形状的实现

本参考对应当前 Pattern Agent 的静态 DXF 装配器。确认当前代码和输入配置，
不将固定展示参数、历史通过数值或当前裁片索引推广到任意服装。

## 从来源到网格

| 阶段 | 实际代码 | 作用 |
| --- | --- | --- |
| 解析及匹配 | [core.py](../../../../services/dxf-preview/converter/core.py) 的 `parse_dxf`、`register` | 读实体、单位、形状与方向，映射到本款配置 |
| 修正与配对 | [sewn.py](../../../../services/dxf-preview/converter/sewn.py) 的 `patterns`、`Builder.add/bind` | 保留原线，另存修正线，定义加工区间、吃势与统一采样 |
| 二维剖分 | 同文件的 `triangulate`、`enforce_boundary` | Delaunay 剖分并补回实际边界约束，避免漏边和 T 形连接 |
| 空间摆放 | `Builder._targets`、`harmonic`、`build` | 声明空间曲线，映射衣身、袖子和领条 |
| 焊接与导出 | `build`、`convert_dxf`、`encode_glb` | 合并对应接缝顶点，统一面方向，输出 GLB |
| 独立重开 | [verification/seams.py](../../../../services/dxf-preview/verification/seams.py) | 从最终文件及原 DXF 重算，不调用生成器 |
| 离线打包与显示 | [app.py](../../../../services/dxf-preview/app.py) 的 `bundle` 及 [renderer.js](../../../../services/dxf-preview/public/renderer.js) | 打包同一 GLB，浏览器使用 WebGL 绘制实际三角面 |

## 走缝规则

当前配置的肩、侧、袖山和袖底存在原线差异，修正另存，最大允许点移 8 毫米。
侧缝前身局部归拢 6 毫米、后身局部拔开 10 毫米；比较加工后的配对长度。
袖山总吃势按项目前 40%、后 60%分配，衣身袖窿保留。领条通过明确负松量
映射到衣身领口；其实际材料伸长能力未测试。

规则来源与冻结阈值见 [缝合合同](../../../../services/dxf-preview/converter/sewing_contract.json)
及 [独立几何验收配方](../../verify/references/dxf-seams.md)。
`bind` 要求加工后配对长度差不超过 0.05 毫米，不能用共同顶点掩盖错误长度或来源。

## 三维形状怎样得到

- 衣身：确定领、肩、袖窿、侧缝和衣摆的空间曲线，在固定边界内对内部顶点做
  图拉普拉斯调和平滑，再按离边界距离增加前后鼓出；边界恢复到目标曲线。
- 袖子：对二维点求解纵向/角向参数，沿预设弯曲轴形成管状。袖围参考袖片截面宽度，
  袖山过渡到前后袖窿曲线；这不是人体手臂扫描或布料平衡求解。
- 领条：沿领口构造折叠领条的显示外层。隐藏内层和缝份叠层没有加入当前外壳。
- 接缝：配对边使用相同采样参数并通过全局顶点合并真正焊接，再由边邻接统一面方向。
  外壳保留四个真实开口，不通过人为封闭领口、袖口获得通过。

`_targets` 中的颈肩位置、衣身鼓出、袖姿和显示材质属于几何构型假定。
内点映射不保证所有边长和角度保持，静态连接 PASS 不构成面料应变、重力下垂、
人体碰撞、压力或实物合身性通过；物理结果须另走有实际求解与独立证据的流程。
