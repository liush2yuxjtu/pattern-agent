# 二维纸样试穿

从现成二维裁片开始。保留输入原件，在副本中导入、装配、模拟和修复。默认从一个目标尺码和自然站姿开始。记录用户指定的其他尺码、姿势和环境。每个约定尺码和姿势均执行相同的验收。

## 从纸样到试穿

1. 按[导入检查](references/verification/pattern/clo3d.md)核对源版本、尺码、单位、已知尺寸、裁片数量、镜像、布纹、对位标记、净缝线与裁剪线。FreeSewing JS 保留生成裁片时的参数和依赖版本。其他二维格式先按实际样本验证尺寸及构造数据。
2. 根据裁片形状、标记和净缝线长度建配缝。回读已缝边、缝向、闭合和预期吃势。记录实际人台尺寸、摆位、面料和物性来源。可推断的输入记录依据。关键配缝或目标尺码存在无法消除的歧义时，完成独立工作后用结构化提问索取缺项。预设面料的结论限于对应的虚拟范围。参见[四类快查](references/workflows.md#四类常见问题)和[验证手册](references/verification/index.md)。
3. 按[运行环境对照](references/runtime-support.md)核对指定 VM、原生应用或求解器及其能力。CLO3D VM 用实际原生操作导入、装配、模拟并保存工程。Boat VM 按用例执行独立求解、故障复现或证据复核，分别记录实际完成的动作。需要 Boat 原生 CLO 时，按[启动与桥接](references/boat-clo-mcp.md)核对虚拟机内的 CLO MCP。运行需要重开工程时，从保存版次读取并核验状态。
4. 在同一保存状态拍摄正面、背面、左侧、右侧和左前 45°。按问题部位补拍局部视图。取出五类验证的图与表。按[五类图表验收](references/pattern-fit-verification.md)逐项审读实际像素和表格读数，再给出判定。
5. 有可修复缺陷时，用[原故障手册](references/verification/index.md)定位该变量，在副本做同条件复测。保留正常基线、故障和修复对应的工程、图表和运行记录。真实原纸样需要改版时，保留原纸样结论及独立候选版结论。

## 放行和交付

五类验证都需要同版的独立图像、可读数据表和明确判据。五类图审与表审全部通过，并且适用的导入、缝合与模拟检查通过，才给该尺码和姿势 `PASS`。已确认有失败时判 `FAIL`。缺图、缺数据、状态错配或缺必需阈值时，补证或复测，可行路径用尽后标 `PENDING`。若已有可信失败，同时记录仍待确认的项目。全部约定尺码和姿势都通过，才在相应范围结案。

默认交付可重开工程、独立证据图、CSV、证据清单和单文件静态 Markdown 试穿报告。用[V2.3 报告模板](references/试穿报告模板.md)和[图片发布器](scripts/publish_report.py)。报告先给出[本轮判断](references/pattern-fit-verification.md#报告排版)，说明适用范围、是否放行、优先处理哪一处及依据。再放五视角及各证据图。有原始设计图和修前证据时，把对照放在开头。输入只有二维纸样时，标出缺少的对照并保留可追溯的纸样基准。集中放五类统计及状态表，最后写「分诊与下一步复测」。用[报告末节检查](evals/check-report-follow-up.py)和[试穿评分器](evals/grade-fit.py)检查最终交付。只把最终 Markdown 放入空目录，验证内嵌图，记录实际阅览器。

本技能的默认报告覆盖约定的 2D 到 3D 试穿范围。若任务包含原技能的正式整衣验收，读[整衣放行规则](references/finish-verification.md)和[四姿势五类验收](references/workflows.md#四姿势五类验收)，通过后使用原[正式报告生成脚本](scripts/bake-report.mjs)。

运行真实评测或添加故障样例时，读取[用例和评分规则](evals/README.md)。
