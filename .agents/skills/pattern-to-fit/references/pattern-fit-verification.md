# 五类图表验收

每个约定的尺码、姿势和候选版形成一个证据单元。同一单元的图与表采用同一已保存的求解状态或匹配的同帧导出。记录工程版次、状态标识、尺码、姿势、人台、面料、闭合和求解器。用来源日志核对状态标识。

| 验证项 | 智能体审查的图 | 智能体审查的表 |
| --- | --- | --- |
| 上身外观 `appearance` | 正面、背面、左侧、右侧、左前 45° 五张独立图。逐图查看领口、衣长、下摆、缝合位置、对称性、异常拉扯和穿模。 | 逐视角或部位记录按款式适用的长度、位置、轮廓、覆盖或闭合观察值，与纸样上的净尺寸、部位标记和可推出的结构预期对照。仅有 2D 时用可追溯的纸样基准。设计线稿有明确要求时按原手册核对。 |
| 应变 `strain` | 记录位置、方向和色标的应变图，覆盖目标部位。 | 给出伸长率、统计口径、取样范围、热点位置和限值。使用原生值，或按匹配 2D 参考和同版 3D 网格复算。 |
| 应力 `stress` | 记录色标及单位的原生应力图，或按同状态原生数据生成的图。 | 保留带单位的原生采样或导出，给出部位、范围、统计量和判据。 |
| 接触压力 `pressure` | 记录色标、单位和接触位置的人体接触压力图，或按同状态原生数值生成的图。 | 保留对应位置的原生压力值、覆盖、统计口径、阈值和来源。压力代理值可作诊断，正式通过取决于匹配的原生证据。 |
| 褶皱与折角 `folds` | 折角图或标注褶皱位置的独立图。 | 用同一保存网格给出部位、折角度数、计算定义、覆盖和判据。 |

原手册按[目录](verification/index.md)查阅。实际数值来自原生导出、原生测点或手册允许的复算路径。保留图例、单位、区域或坐标、样本数或面积覆盖和原始数据。压力、应力要核对原生图的模式。折角图和统计用同一次保存的网格生成。

先定款式、区域和用例的通过条件。用既有规格、已验证的正常基线或已同意的阈值。按证据可支持的范围判定。五项逐项写出看到了什么、表里有哪些读数或结构化观察、与哪个判据比较。图或表显示不合格时记失败。有缺证或无法归属于同一求解状态时重新取证。新证据只更新它能支持的结论。

## 报告排版

用[V2.3 模板](试穿报告模板.md)的首页对照与图片规则。按本技能的节名交付。先写「先看哪里」，交代尺码、姿势、版本和环境。开头直接给出本轮判断和建议动作。说清是否放行、优先处理哪一处，以及哪张图和哪个读数支持。将已经确认的现象与尚待复测的原因分开陈述。写明什么结果会改变建议，例如确认局部压力超过约定限值后，再核查缝合和摆位。全部通过时直接写放行范围和主要依据。

接着写「看整体上身」。有原始设计图、修前和修后证据时，先放首页三图对照，再放五张独立视角。缺原始设计图或修前证据时，在同节标明缺项，保留现有纸样基准及当前试穿图。按部位放应变、应力、压力和折角图，使用图号、部位和单位连接相应统计。将各类关键读数、判据及原始 CSV 链接集中在「集中统计与验收」。其中包含以下五行覆盖表，图审和表审使用 `PASS`、`FAIL` 或 `PENDING`。

| 验证项 | 图审 | 表审 |
| --- | --- | --- |
| appearance | PENDING | PENDING |
| strain | PENDING | PENDING |
| stress | PENDING | PENDING |
| pressure | PENDING | PENDING |
| folds | PENDING | PENDING |

在同一单元标题下放入读数摘要表。表头为 `验证项 | 图号 | 部位 | 读数或观察 | 单位及覆盖 | 通过判据`。每类至少一行。需要补采时写明具体缺项。可按部位加行。各验证项使用上表的英文标识。

多尺码或多姿势报告按证据单元各放一张覆盖表和一张读数摘要表。单元标题格式为 `### 证据单元 M/自然站立`，并与证据清单的 `subject` 一致。正文最后为「分诊与下一步复测」。每张图独占一段并内嵌。保留原始表、清单、求解回执和工程链接。对[评分器](../evals/grade-fit.py)报告的问题修正后重跑。
