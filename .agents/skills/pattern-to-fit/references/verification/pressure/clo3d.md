# 试穿接触压力 · CLO 3D MCP

从同一已存模拟选择原生 Pressure Map，核实当前显示模式、图例、受压位置和闭合状态。用 [CLO 操作约定](../clo3d.md) 发现获支持的原生测点或导出能力，保留实际样本和单位。Fit Map 的类别和接触力向量各自可提供线索，压力数值需要明确的压力读数来源。

普通 Snapshot 省略色标时，直接截取显示原生 Pressure Map 的 3D 视窗，请保留软件渲染的画面、图例与单位。当前只需确认取图时，先交指定的一张图。数值和通过结论须有同版、同姿势、同模拟状态的原生读数。

`mcp__clo_rust__fit_pressure` 可归档同姿势原生 Pressure Map 和记录的 `pressure_kpa` 样本。给出接触区域及统计范围，说明零值纳入方式。只有图时保留视觉发现，数值待验证。
