# Sewing inspector Page files and readback

This surface accepts **saving the checked HTML file and requested Page content**.
It does not certify an interactive embed, browser download or Sites login.
The original destination is the existing women’s fitted-T-shirt introduction
Page; resolve its exact ID from a successful current read or saved native receipt.
Do not invent IDs, create a replacement Page or change sharing.

## File and content gate

1. Run [seam-inspector](seam-inspector.md) on the exact HTML to deliver; save its
   SHA-256 and byte size. For Site export, match the checked packaged file.
2. Read the target Page, guidance and permissions. Follow the Pages write-page
   skill and active editing schema; preserve unrelated content and metadata.
3. Upload the actual absolute file with `write_page_reference`. Require
   `file_access_confirmed`, matching byte size and SHA, and retain the returned
   Markdown/reference exactly. Uploading does not insert it.
4. Read fresh guards and perform the requested link/instruction edits atomically
   using non-patch operations when they must succeed together. Keep the existing
   Site URL, original source files, models and historical FAIL records.
5. Inspect every operation receipt, then reread the affected blocks on the same
   stream. Require exact requested text/reference and accessible file metadata
   with the matching byte size. Preserve IDs/order of untouched blocks. Unknown
   outcomes require reconciliation; never replay an applied/ignored mutation.

Record Page/sequence/block IDs and hashes, file write receipt (digest/size),
targeted readback, exact delivered-file digest, and current scope in dated
evidence. Keep tokens, full account profiles and unrelated Page content out of
verification artifacts. Native write/readback proves bounded persistence; a
real user download must still be opened and hashed if that is the claim.

## Rendering boundary

A normal HTML file link is **not** an executing Page visualization. If an embed
is explicitly requested, use the active `create_page_visualization` capability,
its current size limit and real returned reference; inspect its edit outcome and
rendered viewer. Never paste an iframe or raw HTML into Page prose or claim that
a standalone Site screenshot proves the Page embed works. Preserve saved files
if insertion fails; reread before another upload.
